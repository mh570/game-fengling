## 四、第一次运行怎么做

```
1. Unity 打开工程（首次导入 3–5 分钟）
2. 菜单 Fengling → Build Water Lab Scene
3. 按 Play
```

### 看到什么算成功

- 沙色海岸从脚下延伸到海里
- 水面有蓝色调、能看到闪动的高光
- 岸边有一圈白泡沫
- 走进水里会被浮力托住
- HUD 显示 FPS / 水面高度 / 相对水面高度

### 按顺序排查

| 现象 | 原因 | 修法 |
|---|---|---|
| 水面**粉红色** | shader 编译失败 | 看 Console 的 shader error，把报错发我 |
| 水面**看不见** | `SRPDefaultUnlit` 未被绘制 | 把 shader 里 `LightMode` 改成 `Forward` 再试 |
| 水面**全黑** | 太阳方向或环境探针缺失 | 检查场景里有 Directional Light |
| 水面**平的没波** | `_WaveCount` 为 0 | HUD 按 2 切 Gerstner |
| **人浮在水上方/下方** | CPU/GPU 波参数不同步 | 检查 `FillWaveData` 是否被调用 |
| 帧率**个位数** | 全开在这台机器上正常 | 按 3 切到 Low |

## 五、已知缺口

| 缺口 | 影响 | 补法 |
|---|---|---|
| 折射 | 水下物体没有扭曲 | HDRP Custom Pass 拿不透明纹理 |
| 焦散 | 水底没有光斑 | 同上，或抄 URP-WaterShaders 的做法 |
| 真 FFT | 远景仍有重复感 | 接 Unity HDRP Water System，不自己写 |
| 泡沫生命周期 | 泡沫形状不变，只是滚动 | 加 foam texture + 生成/消散曲线 |
| 水下雾 | 水下只是偏色，没有距离雾 | 加全屏后处理 |

## 六、下一步建议

1. **先跑通，再谈效果** —— 当前最大风险是 shader 没编译过，不是效果不够
2. 跑通后按 HUD 的 3/4/5 试三档，确认低档能到 25+ FPS
3. 按 `6` 切 Spectral，看波形是否比 4 波自然
4. 再决定要不要补折射和焦散（那需要引入 Custom Pass，是另一条工作线）
