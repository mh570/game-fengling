## 技术拆解

### 1. 树冠 = 多个球/面包块拼接

不是单个球：每棵树由 **2~5 个扁球**叠成，尺寸不一，形成团簇感。表面用**色块噪声**打破纯色。

### 2. 树冠轮廓光（关键）

树冠边缘一圈略亮的绿，做法可能是：
- 菲涅尔边缘光（`pow(1-NdotV, k)`）
- 或者把树冠法线朝上的面调亮

**这一圈让树从地面里"跳"出来**，是风格化的核心手法。

### 3. 白色虚线边缘（跨视频的统一签名）

- 水里：岸线白边
- 这里：**路面/台阶/石头边缘的白色虚线**

这是同一个手法：**在"表面边界"画亮线**。可能是屏幕空间的边缘检测（Sobel），也可能是在 shader 里按高度差/法线差画。

**这是两条视频共同的最强风格特征。**

### 4. 树影

树下有**柔和圆形/椭圆形暗斑**（不是精确阴影贴图），像"假影子"。成本极低。

### 5. 全屏白色小点

粒子或程序化噪声撒的白点，营造雨/尘/萤火。

### 6. 低对比 + 冷调

整体像蒙了一层雾，明暗差距很小。

## 我们可以直接用的

| 技术 | 我们现在 | 工作量 |
|---|---|---|
| 团簇树冠 | 没有树 | 中：模型 + 摆放 |
| 树冠轮廓光 | 没有 | **小：菲涅尔项** |
| **白色虚线边缘** | **完全没有** | **小：边缘检测后处理** |
| 假影子 | 有 blob shadow（角色） | 小：扩展到树 |
| 全屏白点 | 没有 | 小：粒子 |
| 低对比冷调 | 偏写实、对比强 | 小：调色 |
