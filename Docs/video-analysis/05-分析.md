## 技术拆解

### 1. 整个游戏是「像素风 3D」

不是"3D 环境 + 2D 精灵"，而是 **3D 模型本身呈现像素化**。实现方式二选一：

| 方式 | 说明 |
|---|---|
| **低分辨率渲染 + 放大** | 场景渲到 480×270，点采样放大。所有物体自动像素化 |
| 像素化贴图 | 每张贴图都是低分辨率像素画，配合点采样 |

**从画面看两者都有**：草地贴图是像素画，边缘也有低分辨率渲染的锯齿。

### 2. 草地的 dithering

草地不是纯色，是**两种绿交替的抖动图案**——这是像素画里表现渐变的经典手法。

### 3. 花的处理

花是**面片精灵**（billboard 或 gizmo），成簇摆放，不是模型。

### 4. 影子

柔和边缘，说明有阴影贴图 + 模糊，不是硬边。

---

## 我们可以直接用的

| 技术 | 我们现在 | 工作量 |
|---|---|---|
| **低分辨率渲染** | 没做 | 小（一个 RT + 点采样） |
| **像素贴图 + 点采样** | 没有贴图 | 中（要生成/找像素纹理） |
| 草地 dithering | 没有 | 小（shader 里两色交替） |
| 花是精灵面片 | 没有 | 小 |
| 柔和阴影 | 有级联阴影，偏硬 | 小（软化） |

---

## 关键结论（对项目的冲击）

**参考视频是一个完整的像素风 3D RPG，不是"风格化低多边形"。**

我们之前定的"风格化美术规范"（平滑低多边形 + 有限调色板）**方向偏了**——
正确方向是：

1. **低分辨率渲染**（必须，这是像素感的根）
2. **像素化贴图**（草地/木头/石头都要）
3. **精灵面片做花草**
4. **角色也用同一套像素化**

这解释了为什么之前用平滑低多边形资产总觉得"不像"。
