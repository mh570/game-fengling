## 技术拆解

### 1. 水的颜色来自深度

`color = lerp(shallowColor, deepColor, depth)`，深度来自场景深度图或水面到水底的距离。**不是**靠菲涅尔。

### 2. 水是半透明的，能看到底

水面 shader 的 alpha 随深度增加，浅处几乎全透明。所以**水底的地形/石头必须真的存在**，不能只是贴图。

### 3. 岸线白边（这是最容易漏的细节）

陆地边缘一圈**白色虚线/实线**，做法可能是：
- 深度差检测：`abs(sceneDepth - waterDepth) < threshold` → 白色
- 或者地形 shader 里按"到水面的高度差"画白边

**这个效果让画面立刻有"手绘插画"感**，是风格化的关键。

### 4. 水面高光是离散短划痕

不是物理镜面反射，是**程序化噪声撒的白线**：稀疏、随机朝向、长度相近。

### 5. 远景雾

远处的岛和水都淡入浅蓝灰，掩盖地图边界。

### 6. 鱼

简单长条网格 + 摇摆动画 + 阴影。数量多但单个极简。

## 我们可以直接用的

| 技术 | 我们现在 | 工作量 |
|---|---|---|
| 深度渐变水色 | 有深度图，但水色偏暗且写实 | 小：改 shader 颜色映射 |
| 半透明看底 | 有折射但很弱 | 中 |
| **岸线白边** | **完全没有** | **小：深度差阈值** |
| 离散水面高光 | 有波场，但高光连续 | 小 |
| 远景雾 | 已有距离分级雾 | 已完成 |
| 鱼群 | 没有 | 中 |

## 我们需要新做的

1. **岸线白边**（性价比最高，一行深度判断就能出效果）
2. **水的浅/深双色 + 透明度随深度**
3. **离散高光**替换连续镜面
4. 鱼群（Instancing + 简单摇摆）
