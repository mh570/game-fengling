## 三、技术拆解

### 1. 树冠：多团块拼接 + 像素贴图

每棵树 canopy 由 **3~6 个圆润团块**叠加，每个团块用**低分辨率像素贴图**，
表面能看出叶子是一小片一小片的像素块（不是光滑渐变）。

**这直接推翻了"用 Quaternius 那种平滑模型"的路线。**

### 2. 树影：深绿色、有角度

不是黑色半透明圆斑，而是**深绿色**（和环境色相近）的暗斑，
边缘是**多边形/有角度**的，不是圆形。

**做法推测**：一颗"影子投影体"网格（简化树冠轮廓），用深绿半透明材质贴地。

### 3. 草地：底 + 斑块 + 抖动

三层信息：
1. 浅绿底色
2. 深浅不一的**大斑块**（低频噪声）
3. **像素级抖动**（高频）

### 4. 花与蝴蝶：精灵

都是小精灵（billboard），尺寸小、数量多。

## 四、我们可以直接用的

| 技术 | 说明 | 成本 |
|---|---|---|
| **树冠多团块 + 像素贴图** | 程序化生成 3~6 个球拼一棵树，配像素纹理 | 中 |
| **深绿色角度树影** | 简化轮廓网格 + 深绿材质 | 小 |
| **草地三层（底+斑块+抖动）** | shader 里叠加 | 小 |
| 花/蝴蝶精灵 | 面片 + 随机摆放 | 小 |
