# 二、分阶段分析流程（为了控制上下文）

视频总共 364 帧，一次全看会淹没上下文。所以按阶段来：

## 阶段 A：抽帧归档 ✅ 已完成

- 下载 7 个视频（1080p）
- 每 3 秒抽一帧
- 建立本索引

## 阶段 B：逐视频分析（每次会话做 1~2 个）

对每个视频：

1. 挑 **6~10 张代表性帧**（开场/中段/高潮/收尾）
2. 记录：画面构成、颜色、光照、材质、运动
3. 提炼：**用了什么技术手段**
4. 输出：`<ID>-分析.md`

**产出模板**：

```markdown
# <ID> <标题>

## 画面
## 技术拆解
## 我们可以直接用的
## 我们需要新做的
## 关键帧索引
```

## 阶段 C：横向汇总

把所有视频的技术点合并成一张表：

| 技术 | 出现在哪些视频 | 优先级 | 我们的现状 |
|---|---|---|---|

输出 `00-横向汇总.md`。

## 阶段 D：落到项目

把汇总表映射到 `Docs/总任务.md` 的差距表，排进阶段计划。

# 四、已知的关键结论（阶段 B 已完成部分）

## 03 · GodRay 视频

- 字幕原文："绘制平行于光线且垂直于视角的面片，并进行叠加"
- 字幕原文："进行调参柔和"
- **结论**：不是光线步进，是**面片叠加式**体积光
- 优势：不依赖后处理链、能真实遮挡、风格化友好
- 详见 `../analysis/09-参考风格-风格化森林与面片体积光.md`

## 画面风格（跨视频共同点）

- 俯视 45~55°
- 低多边形 + **像素化边缘**（推测是低分辨率渲染）
- 有限低饱和调色板
- 柔和阴影、高环境光
- 竖直光柱从树冠缝隙漏下
