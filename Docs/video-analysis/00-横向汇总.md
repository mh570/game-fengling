---

# 一、结论：这是「像素风 3D 立体场景」

不是"风格化低多边形"，也不是"3D + 2D 精灵"，而是：

> **3D 模型 + 低分辨率渲染 + 像素化贴图**
> 整体看起来像"会动的像素画"，但有真实的立体感和光照。

**这一条推翻了我们之前定的"平滑低多边形"方向。**

---

# 二、风格规格（跨视频一致）

| 维度 | 规格 | 依据 |
|---|---|---|
| **渲染分辨率** | 约 **480×270 ~ 360×200**，点采样放大 | 05/06 能看到像素格 |
| **贴图** | 低分辨率像素画，点采样 | 05 草地、06 花草 |
| **草地** | **两色抖动**（dithering）表现明暗 | 06 |
| **花草** | **精灵面片**成簇摆放 | 05/06 |
| **阴影** | **柔和 blob 暗斑**，不是精确阴影 | 05/06 |
| **调色板** | 有限、低饱和、偏冷绿 | 全部 |
| **视角** | 俯视 45~60°（RTS 感），局部有近景 | 01/02/06 |
| **细节粒子** | 蝴蝶、白点、雨丝 | 05/06 |

# 四、对当前项目方向的影响

## 4.1 之前的判断错了

| 之前定的 | 实际参考要求 |
|---|---|
| 平滑低多边形（Ghibli 风） | **像素化 3D** |
| 有限调色板（对） | 有限调色板（对） |
| 低分辨率渲染（对） | **必须**，不是可选 |
| 地表色块按高度分 | 还要加**两色抖动** |
| 写实光照 | 低对比、高环境光 |

## 4.2 资产方向要改

| 之前 | 现在 |
|---|---|
| Quaternius（平滑 Ghibli） | ❌ 风格不符 |
| Pixor 像素风树（CC0） | ✅ 正确方向 |
| CC0Tree（blockout） | 🟡 可作占位 |

## 4.3 地形方向

Unity Terrain 与自建 SRP 冲突（已验证：patch 实例化数据拿不到）。
市场做法是**自建网格地形 + 顶点颜色**（Polaris / Tiny Terrain 等）。
**建议按此执行**，并在 shader 里加两色抖动。

# 六、04/07 新增的关键发现

## 视口缩放是核心设计（04）

那个 Godot 视频的调试面板直接写着：

```
视口缩放 x0.56 / x0.69 / x1.00     ← 可调！
```

**像素化不是固定分辨率，是可调节的渲染缩放**。这比"写死 480×270"更灵活，而且玩家可以调。

面板还列出了完整系统清单：
`☑ 萤火虫 ☑ 树叶透视 ☑ 云影 ☑ 光束 ☑ 光晕分层`

## 树的做法（07，最佳参考）

- 树冠 = **3~6 个像素化团块**拼成，每块用低分辨率像素贴图
- 有**红色浆果**点缀
- 树影 = **深绿色、有角度的暗斑**（不是黑色圆斑）
- 草地 = 浅绿底 + 大斑块 + 像素抖动（三层）

## 影子风格统一

05/06/07 都是**深色系（深绿/墨绿）的有角度暗斑**，
不是我们现在的黑色椭圆。
