# 06 · 稻草人找到了自己的麦田

**来源**：<https://b23.tv/Dwfoesj>（151 秒，50 帧）
**看过的帧**：`frames/06-scarecrow/f_001.jpg`

---

## 画面

俯视约 60°，一片开阔草地：

- **草地**：深绿 / 浅绿两色**抖动（dithering）**，能看见单个像素块
- **紫色花丛**：成簇分布，明显是**精灵面片**，边缘是硬像素
- **稻草人**：3D 模型 + 像素贴图，戴帽、蓝衣、木架手臂
- **蝴蝶**：白色小精灵，飘在空中
- **阴影**：花丛和稻草人下方有**柔和的不规则暗斑**
- 整幅画面有**明显的像素网格**（低分辨率渲染放大）

---

## 技术拆解

### 1. 低分辨率渲染是确定的

画面能看到规则的像素格，不是"低多边形"造成的，是**渲染分辨率低 + 点采样放大**。

估算：1080p 画面里，一个"像素块"约占 3~4 个显示像素 → 渲染分辨率约 **480×270 ~ 360×200**。

### 2. 草地 = 两色抖动

不是贴图噪声，是**两种绿色按棋盘/随机规则交替**，用来表现明暗过渡。
这是像素画表现渐变的经典手法。

### 3. 花丛 = 精灵面片成簇

每簇花是**一张像素精灵**，按固定图案重复摆放，不是每朵花一个物体。

### 4. 影子 = 柔和暗斑

不是阴影贴图，是**贴地的半透明暗斑**（blob shadow），边缘虚化。

### 5. 整体色调

- 草地：从深绿 `#3A5A2A` 到浅绿 `#8FB86A`
- 花：紫 `#7A5FA8`
- 稻草人：蓝灰 `#4A5A7A` + 木色 `#8A6A42`
- 强调低对比、高环境光

---

## 我们可以直接用的

| 技术 | 说明 |
|---|---|
| **低分辨率渲染** | 480×270 → 点采样放大，这是核心 |
| **两色抖动草地** | shader 里按 uv 做棋盘/哈希交替 |
| 花丛精灵 | 一张图 + 重复摆放 |
| Blob 影子 | 我们已有（`PlayerBlobShadow`），扩展到所有物体 |
| 蝴蝶粒子 | 小精灵 + 飘动 |
