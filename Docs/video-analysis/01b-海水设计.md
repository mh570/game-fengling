**日期**：2026-11-21

| 项 | 参考 01（浅水） | 我们的海 |

# 二、沿用参考 01 的三个手法（已决定全部沿用）

1. **深度双色**：`lerp(浅色, 深色, depth)`
2. **岸线白边**：深度差阈值 → 白色
3. **离散高光**：程序化撒的白色短划痕（不是镜面反射）

---

# 三、海的三段式设计（"全都要"）

## 3.1 近岸（0 ~ 80m 距离）

- **能看见水底**：沙、石头、海草透过水面可见
- 水色：浅青 `#7FC4C8`
- 透明度高（alpha ≈ 0.25）
- **岸线白边**：深度差 `|sceneDepth - waterDepth| < 0.3` → 白色，宽度约 3~8 像素
- **白浪**：在坡度大的地方（岩石、礁石）自动生成，周期性涨落

## 3.2 中景（80 ~ 400m）

- 看不到水底
- 水色：蓝绿 `#4A8FA8`
- 透明度中（alpha ≈ 0.75）
- 有**波浪起伏**（顶点位移或法线扰动）
- 太阳低角度时出现**波光带**

## 3.3 远景（400m+）

- 深蓝 `#2E5F80`
- 几乎不透明
- 与雾混合，**化入天际线**
- 只保留低频波浪

# 四、岩岸白浪（自动生成）

**做法**：用**水深变化率**（坡度）驱动的泡沫阈值

```hlsl
float shore = saturate((waterDepth - foamStart) / (foamEnd - foamStart));
float slope = length(ddx(worldPos), ddy(worldPos));   // 或用深度梯度
float foam = smoothstep(0.5, 0.9, slope) * shore;
foam *= 0.6 + 0.4 * sin(_Time.y * 1.5 + noise);       // 周期性涨落
color = lerp(color, white, foam);
```

**效果**：礁石、坡度大的岸边自动出现游动的白浪，平坦沙滩没有。

# 五、三种水体的参数表

| 参数 | 海 | 湖 | 河 |
|---|---|---|---|
| 浅色 | `#7FC4C8` | `#8FCFC0` | `#9FD8D0` |
| 深色 | `#2E5F80` | `#3A7A78` | `#4A8A88` |
| 可见水底距离 | 80m | 全湖可见 | 全河可见 |
| 透明度（近） | 0.25 | 0.15 | 0.15 |
| 透明度（远） | 0.95 | 0.55 | 0.45 |
| 浪高 | 高 | 低 | 中（有流向） |
| 白边强度 | 强 | 中 | 中 |
| 岩岸白浪 | 有 | 无 | 无 |
| 波光 | 强 | 弱 | 弱 |

---

# 六、实现顺序

1. **水的 shader 参数化**（浅/深色、透明度曲线、可见底距离）
2. **岸线白边**（深度差阈值）
3. **三段式颜色混合**（按世界空间到岸线的距离或水深）
4. **岩岸白浪**（坡度驱动）
5. **波光**（太阳低角度 + 噪声）
