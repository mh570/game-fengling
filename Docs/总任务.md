# 三、阶段计划

## 阶段 1：地形打通（当前）

1. 创建 Unity Terrain，Import Raw（1025，Min -50 / Max 478.6）
2. 写 `Fengling/Terrain` shader（splat 分层 + 我们的太阳/云影）
3. 保留 `ITerrainSampler` 抽象（为将来体素/破坏留接口）
4. 验证：截图能看到沙滩/草/林/岩分带

## 阶段 1.5：低分辨率像素渲染（2026-11-21 决定）

**为什么**：参考视频的"像素感"来自**低分辨率渲染 + 放大**，不是资产本身。
社区标准做法（retro post-process）：渲染到 480×270 的 RT，再用点采样放大到 1080p。

**好处**：任何低多边形资产都会自动变成阶梯状边缘，不需要买像素风资源包。

**做法**：
1. 管线里加一个低分辨率 RT（480×270）
2. 所有 pass 渲到这个 RT
3. 最后用 `FilterMode.Point` 放大到屏幕

**参数**：宽高比 16:9，基准 480×270（可配置 320×180 / 640×360）

**验证**：与参考帧对比，边缘应该出现同样的阶梯锯齿

## 阶段 2：地表与植被

1. 按 Skye 高程重定分带阈值
2. 导入 Quaternius 树（CC0）→ 3 档 LOD
3. 草色块 + instanced 草片
4. 石头/花散落
5. 验证：与参考图并排对比

## 阶段 3：体积光柱（核心）

1. 面片叠加式光柱（参考视频做法）
2. 与阴影联动（树影投在地上，光从缝隙漏下）
3. 验证：参考帧对比

## 阶段 4：体积云穿光

1. 修着色器数学（t0/t1 求交）
2. 输出透射率给光柱
3. 验证：云缝有光柱、密云无

## 阶段 5：整体调色与质感

1. 统一调色板
2. 阴影柔和化
3. 水面风格化
4. 验证：与参考视频逐帧对比
