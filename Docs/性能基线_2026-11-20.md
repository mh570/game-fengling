# 720p 性能基线

**日期**：2026-11-20  
**分辨率**：1280×720  
**场景**：RpgLab  
**方法**：固定 RT + 每帧 1px 读回强制 GPU 同步，90 帧，剔除不了编辑器开销

> 这是相对基线，不是打包后真机数据；读回本身也有成本。

---

## 结果

| 场景 | 平均 ms | P50 ms | P95 ms | P50 FPS |
|---|---:|---:|---:|---:|
| 晴天 12:00 | 34.33 | 29.35 | 31.46 | 34.1 |
| 夜间 22:00（月影） | 33.16 | 29.67 | 36.75 | 33.7 |
| 阴天 12:00 | 35.70 | 31.19 | 39.21 | 32.1 |
| 雨天 12:00 | 35.81 | 32.04 | 39.85 | 31.2 |

原始数据：`D:/item/game/p9_perf.csv`

## GodRay 对照

同一机位朝太阳：

| 项 | P50 ms |
|---|---:|
| GodRay 关闭 | 29.11 |
| GodRay 开启（32 步 × 3 tap） | 34.27 |
| GodRay 开启（16 步 × 3 tap） | 32.94 |

结论：

- 径向 GodRay 约 **+5.2ms**
- 16 步只省约 0.5ms，但画质明显更差
- 已恢复 32 步
- GodRay 改为**只在雾/霾天气启用**，晴天不付这笔成本

## 云影优化（2026-11-20）

地面/水面云影从 3 层 noise 降到 2 层：

- 低频形状 0.65
- 一层细节 0.35
- 阈值同步调整

复测（噪声较大，作为趋势）：

| 场景 | P50 前 | P50 后 |
|---|---:|---:|
| 阴天 | 31.70 | 30.10 |
| 雨天 | 31.48 | 44.06（异常尖峰，不可信） |

结论：

- 阴天云影约省 1.6ms
- 雨天数据被尖峰污染，需重测
- 云影视觉仍成立

## 真机 Player（Windows standalone）

构建：

`BuildBenchmarkPlayer.Run` → `D:/item/game/Build/FenglingBench.exe`

运行：

```text
FenglingBench.exe -benchmark -screen-width 1280 -screen-height 720 -screen-fullscreen 0
```

探针：`RuntimePerformanceProbe`，四组场景，60 帧预热 + 180 帧采样，`FrameTimingManager` + CPU 兜底。

| 场景 | 优化前 CPU P50 | 优化后 CPU P50 |
|---|---:|---:|
| 晴天 12:00 | 10.96 | 10.70–11.74 |
| 夜间 22:00 | 8.68 | 8.65–8.71 |
| 阴天 12:00 | 25.02 | 10.66–10.72 |
| 雨天 12:00 | 25.25 | 11.12 |

优化：高云量 / 强雨关闭体积雾与 GodRay。

结论：

- 阴天从 25ms 降到 **10.7ms**
- 雨天从 25ms 降到 **11.1ms**
- 当前四组约 **9–12ms CPU**，约 85–115fps
- GPU FrameTiming 在该构建/API 下返回 0，暂只有 CPU 数据
