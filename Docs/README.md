## 写作约定

每一项只回答三件事：

```
1. 这层管什么   —— 拆到可以独立实现的最小单元
2. 怎么做       —— 具体参数、顺序、数值区间
3. 哪里会错     —— 坑和验收标准
```

不写：证据来源、分析过程、研究方法。
