## 0. 上一版为什么没达标

| 你的批评 | 我的问题 | 修正方向 |
|---|---|---|
| 天上没云，不像晴天，像晚上 | 只加了 PBR 天空，没加云层，太阳角度也偏低 | 加体积云 + 抬高太阳 + 用固定曝光对齐白天 |
| 浪是左右的形式 | 4 个 Gerstner 波方向集中在同一侧，形成规则条纹 | 多方向 + 频谱扰动，破掉可见周期 |
| 不是 RPG 俯视角，是第一人称 | 我把相机做成了第一人称 | 改成第三人称俯视角（RPG 标准机位） |
| 浪不是自然波动 | 波数少、方向规律 | 用频谱合成的 16 波（已有 `SpectralWaterSimulation`）+ 交叉方向 |
| 泡沫不够自然 | 只有一条平滑白带 | 深度带 + 噪声扭曲 + 不规则宽度 |
| 水是墨绿的，不透明 | 全程不透明，深色直接铺满 | **改成按深度透明的 alpha 混合**，浅处见底 |
| 闭门造车 | 没看现成实现 | 见第 1 节，按参考项目的做法改 |

## 1. 参考项目（真实存在，已核对源码/文档）

| 项目 | 许可 | 它解决我们哪个问题 |
|---|---|---|
| [MatrixRex/Uber-Stylized-Water](https://github.com/MatrixRex/Uber-Stylized-Water) | MIT | 透明水、深浅双色、**表面泡沫 + 插入泡沫**、世界空间 UV、岸线动画、焦散、折射、镜面高光分组、平面反射 |
| [Roystan/ToonWaterShader](https://github.com/IronWarrior/ToonWaterShader)（Roystan 教程源码） | Unlicense | **深度差泡沫**的标准写法：`depth = sceneDepth - surfaceDepth`，阈值 + 噪声 |
| [Alex Ameye 风格化水教程](https://ameye.dev/notes/stylized-water-shader/) | 文章 | 上面那个项目的灵感来源，讲清了"为什么用世界空间 UV"和"泡沫要扭曲" |

### 从它们身上直接照搬的 4 个做法

1. **世界空间 UV**（不是物体 UV）—— 多块水面拼接不会出现接缝，也不会随物体缩放拉伸
2. **深度差泡沫** —— `depth = 水面深度 - 场景深度`，越浅泡沫越强；不是"画一条白边"
3. **深浅双色 + 深度插值** —— 浅处 `shallowColor` 接近透明，深处 `deepColor`
4. **表面泡沫带扭曲** —— 用噪声扰动泡沫的 uv，边缘才不会像刀切

## 2. 六项验收标准

> 每条都要能"看照片判断"，不能含糊。

### A. 天空：白天，有云
- [ ] 天空是蓝色渐变，**地平线附近更亮**
- [ ] 画面上半部分能看到**至少一片云**
- [ ] 整体亮度：截图平均亮度 ≥ 0.35（0–1），不再是"夜晚感"
- [ ] 太阳在侧上方（仰角 35–50°），不是贴着地平线

### B. 机位：第三人称俯视（RPG）
- [ ] 相机在角色**后上方**，高度 ≥ 5 m
- [ ] 俯角 **40–60°**
- [ ] 画面下方能看到角色本体（胶囊或模型）
- [ ] 相机跟随角色，不是固定在场景里

### C. 水色：按深度透明
- [ ] **浅水区能看见沙底的地形颜色**（不是一片纯色）
- [ ] 从浅到深有连续过渡，不是硬边
- [ ] 深水区是青蓝/深蓝，**不允许整体墨绿**
- [ ] 水面上能看到天空颜色的反射（亮部偏天空色）

### D. 波浪：不规则
- [ ] 浪向 ≥ 3 个不同方向（Scene 视图线框可验证）
- [ ] 同一屏内**看不出重复的条状图案**
- [ ] 浪的大小不均匀：有大起伏也有小碎波
- [ ] 波形随时间连续变化，无跳变

### E. 泡沫：自然
- [ ] 岸边有**宽度变化**的白色泡沫带（不是等宽白线）
- [ ] 泡沫边缘**破碎**（有齿状/絮状，不是平滑渐变）
- [ ] 泡沫随时间流动
- [ ] 浪尖也有少量泡沫

### F. 性能
- [ ] High 档 ≥ 30 FPS（1280×720，这台机器）
- [ ] Low 档 ≥ 50 FPS
- [ ] 切换档位不重建场景

## 3. 实施方案

### 3.1 天空（A）
- `PhysicallyBasedSky` 保留，太阳仰角改 **42°**
- Volume 里加 **Volumetric Clouds**（HDRP 自带），调低密度让云可见
- 曝光改固定 **EV 12.5**，对着白天校准
- 如果体积云太慢（2 核机器），退化成 **HDRP 的 Cloud Layer** 或一张静态云纹理铺在天空上

### 3.2 机位（B）
- 新增 `ThirdPersonCamera.cs`：跟随玩家，偏移 `(0, 6.5, -8)`，俯角约 48°
- 玩家改成"移动方向跟随相机朝向"（RPG 常规）
- 相机加简单避障（可选，先不做）

### 3.3 透明水（C）
**关键改动**：shader 从 `Opaque` 改为 `Transparent`
```
Tags { "Queue"="Transparent" "RenderType"="Transparent" }
ZWrite Off
Blend SrcAlpha OneMinusSrcAlpha
```
`alpha = saturate(depth / _FadeDistance)`：
- 水深 0 → alpha 0 → 完全透出沙底
- 水深 ≥ fadeDistance → alpha 1 → 深水不透

颜色改为：
```
shallowColor ≈ (0.55, 0.85, 0.85)  清透青
deepColor    ≈ (0.02, 0.18, 0.30)  深蓝
```
去掉现在的墨绿 `(0.05,0.42,0.45)`。

**代价**：透明物体不写深度，水面与水面自身重叠时会有排序问题 —— 我们只有一层水面，可接受。

### 3.4 不规则浪（D）
- 默认实现切到 `SpectralWaterSimulation`（16 波，Phillips 谱）
- 频谱参数：`windDirectionSpread` 拉到 120°，让方向充分散开
- shader 的 `MAX_WAVES` 已经是 16，无需改
- 加一层**低频噪声调制振幅**（`amplitude *= 1 + 0.3*noise(x,z)`），破掉规则感

### 3.5 泡沫（E）
三层：
```
depthMask  = (1 - depth/foamWidth)²          基础带
warp       = 噪声扰动世界坐标，再算 depthMask   ← 破掉等宽
coreLine   = (1 - depth/(foamWidth*0.2))      贴水线硬核
foam       = (depthMask*(0.4+0.6*noise) + coreLine*0.5) * strength
```
关键新增：**用噪声扭曲采样坐标**（`xz += (noise-0.5)*warpStrength`），泡沫边缘才会碎。

### 3.6 性能（F）
- 体积云是大头，优先做成可关（Low 档关）
- 低档：关泡沫、关反射、法线单层

## 4. 验收流程（每轮）

1. 改完 → 重建场景 → 用 `WaterLabAutoCapture` 渲一张 1280×720
2. 对照第 2 节逐条打勾
3. 没过的项：**写明原因**（是参数不对、还是根本没实现），再改
4. 全过 → 提交推送
