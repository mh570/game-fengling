# RPG 相机 + 昼夜/太阳系统执行方案

**日期**：2026-11-20  
**基线**：`main` / `98fc03d`（线性 Shadow Map 已跑通）  
**目标**：Manor Lords 式自由 RTS 相机 + 24h 太阳/月亮/星空 + 4 级阴影 + 水面倒影联动  
**原则**：一次只改一个系统；每步可截图验收；每步单独提交；不把未验证代码留在 `main`。

## 1. 总体架构

```text
RpgLab / 正式场景
├─ RtsCameraRig
│  ├─ RtsCameraController      输入、平滑、旋转/缩放/平移
│  ├─ RtsCameraCollision       地形/水面碰撞、边界
│  └─ RtsCameraFocus           聚焦玩家/返回自由
├─ TimeOfDaySystem
│  ├─ SolarPosition            太阳方位/高度、日出日落
│  ├─ MoonPosition             月亮方位/高度/相位
│  ├─ SkyController            天空盒颜色、太阳盘、星空
│  ├─ LightingController       太阳/月亮颜色强度、环境光、曝光、雾
│  └─ WeatherController        晴/云/雨/雾（先视觉）

   └─ 水面高光/泡沫/颜色       按时间与天气调参
```

## 2. 相机规格（Manor Lords 式）

### 2.1 操作

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 水平平移（相对相机朝向） |
| 鼠标滚轮 | 缩放（透视距离，不是 FOV 突变） |
| 中键拖拽 | 旋转 yaw + pitch |
| Q / E | 左右旋转 yaw |
| 鼠标边缘 | 可选边缘平移（默认关闭，避免误触） |
| Space | 聚焦玩家 / 退出聚焦 |
| 鼠标中键点击 | 可选：聚焦点 |

### 2.2 参数

- 透视 FOV：45°
- 距离：15–120m
- 俯角：35°–75°
- 旋转：yaw 自由，pitch 限制
- 平移速度：随距离缩放
- 平滑：位置/旋转 `SmoothDamp`
- 碰撞：相机不穿地形、不低于水面 + 0.5m
- 边界：地形尺寸内；不飞出海面无限远

### 2.3 验收

- 七套场景都能平移/旋转/缩放
- 相机不穿地、不穿水
- 聚焦玩家后能退出回自由
- 手感接近 RTS，不是第一人称/轨道相机

## 3. 时间系统规格

### 3.1 时间模型

- `timeOfDay`：0–24
- `day`：1–30
- `season`：春/夏/秋/冬
- `year`
- 默认：1 现实秒 = 1 游戏分钟（24 现实分钟 = 1 游戏日）
- 支持暂停、1x/2x/4x、拖时间条

### 3.2 太阳/月亮

- 太阳方位角/高度由时间 + 纬度 + 季节赤纬计算
- 日出/日落阈值、太阳颜色/强度曲线
- 月亮与太阳大致相对，夜晚弱冷光
- 星空随时间旋转，夜晚淡入
- 太阳/月亮都驱动：
  - 方向光旋转
  - 阴影方向
  - 水面高光
  - 平面反射中的天空/太阳

### 3.3 天空/环境

- 天空盒：白天蓝、黄昏橙、夜晚深蓝/黑
- 太阳盘、月亮盘、星星
- 环境光/SH 随时间变化
- 雾/曝光曲线随时间变化
- 天气：晴/云/雨/雾（先视觉）

### 3.4 验收

- 拖时间条 0:00–24:00，太阳/月亮/天空连续变化
- 日出/日落颜色和阴影方向正确
- 夜晚有月光/星空，不是纯黑
- 水面高光/倒影跟随太阳/月亮

---

## 4. 阴影规格

- 4 级级联，线性 RFloat shadow map
- 级联分割：近/中/远/最远
- 更新：太阳角度变化 > 阈值，或相机移动 > 阈值
- 静止时复用
- 先保证方向正确，再调 bias/分辨率

### 验收

- 玩家/道具投影方向随太阳变化
- 近处阴影清晰，远处不闪
- 时间拖动时阴影连续更新，不跳变
- 水面不被误判为 caster

---

## 5. 水面联动

- 平面反射每帧更新（已实现）
- 太阳/月亮方向写入水面 shader
- 高光强度/颜色随时间变化
- 天空/太阳/月亮进入反射
- 夜晚水面不变成纯黑，保留月光/环境色

### 验收

- 6:00 / 12:00 / 18:00 / 0:00 四个时间点截图
- 倒影方向与太阳/月亮一致
- 无白斑/硬条纹
- 七套场景不回归

## 6. 执行阶段（按顺序）

### Phase 0：冻结基线

- 从 `main` 开 `p9-camera-time`
- 记录当前 `98fc03d`
- 不改水/阴影，只建 `RpgLab` 测试场景

### Phase 1：相机（先独立）

1. `RtsCameraController` 骨架 + 输入
2. 平移/缩放/旋转/平滑
3. 地形/水面碰撞 + 边界
4. 玩家聚焦/退出
5. 七套场景迁移
6. 截图验收 + 提交

### Phase 2：时间核心

1. `TimeOfDaySystem` 时钟/调速/拖拽
2. 太阳方位/高度 + 方向光
3. 天空颜色/太阳盘
4. 月亮/星空
5. 环境光/曝光/雾
6. 截图验收 + 提交

### Phase 3：阴影

1. 太阳 4 级级联数据/atlas
2. 采样与级联选择
3. 按需更新
4. 月亮单独一套低分辨率 shadow map（真实投影）
5. 七套场景验证
6. 截图验收 + 提交

### Phase 4：水面联动

1. 太阳/月亮方向进水面
2. 高光/颜色随时间
3. 反射包含太阳/月亮/天空
4. 四时间点截图
5. 提交

### Phase 5：季节/天气

1. 季节赤纬/日照长度
2. 晴/云/雨/雾视觉
3. 天气对水面/光照影响
4. 提交

### Phase 6：总体验收

- 七套场景 + 四时间点
- 相机/时间/阴影/倒影无回归
- 文档更新

## 8. 风险

1. **4 级级联 + 每帧反射 + 全分辨率深度** 在 UHD 710 上可能很重；当前按“画面优先”，但 Phase 6 必须做一次性能采样。
2. **季节/天气** 范围大；先做视觉，不做农作物/玩法。
3. **月亮阴影** 成本高；先决定月亮是否投真实阴影。
4. **Manor Lords 相机** 的边界/碰撞/边缘滚动需要手感调参，不能一次定死。

---

## 9. 最终锁定

1. 季节/天气：**只做视觉**，不做玩法。
2. 月亮：**投真实阴影**，需要第二套 shadow map/级联。
3. 默认一天：**24 现实分钟**。
4. 相机：**边缘滚动默认关闭，Space 聚焦玩家**，中键拖拽旋转，Q/E 旋转。
5. Git：**继续 `main`**，按 Phase 逐步提交，失败回滚。
