## 1. 五个图层与依赖关系

水面看起来是一整块，实际是五层叠加。每一层都能单独实现、单独验收。

| 层 | 它负责的"感觉" | 依赖 | 能省吗 |
|---|---|---|---|
| **1 几何波形** | 海平线起伏、大形状 | 无 | 只在极简场景可省 |
| **2 法线** | 近景的"水感" | 网格 | **不能省** |
| **3 高光** | 闪光、湿润感 | 法线 | **不能省** |
| **4 颜色深度** | 透、浑、深 | 深度缓冲 | 可简化 |
| **5 泡沫** | 岸线、浪尖 | 深度缓冲 | 可省（但会缺"岸"） |

依赖是单向的：

```
网格 → 波形位移 ─┐
                 ├→ 法线扰动 → 高光
深度缓冲 ────────┴→ 颜色/泡沫
```

**法线是高光的输入**——法线错了，高光再怎么调都是错的。这是新手最容易搞反的顺序。

### 视觉权重 vs 性能权重

| 层 | 视觉贡献 | 性能开销 |
|---|---|---|
| 法线 | ★★★★★ | 极低 |
| 高光 | ★★★★★ | 极低 |
| 反射 | ★★★★ | **极高** |
| 颜色深度 | ★★★ | 低 |
| 波形 | ★★（近看）★（远看） | 中高 |
| 泡沫 | ★★ | 低 |

**结论：把钱花在法线和高光上，把预算从反射里省出来。**

## 2. 几何与波形

### 2.1 网格要多密

先接受一个事实：**网格永远不够密。**

HDRP 的细分上限是：

```
k_WaterTessellatedMeshResolution = 128      → 128×128 = 16,384 格
tessellationFactorFadeStart      = 150 m    → 150 m 内全细分
tessellationFactorFadeRange      = 1850 m   → 到 2 km 完全不平铺细分
```

1 km 的水面，每格约 8 米。**靠几何做不出 10 cm 的波纹**——这是第 3 章存在的理由。

网格的三档选择：

| 方案 | 顶点数 | 适用 |
|---|---|---|
| 一张大平面（2 三角形） | 4 | 平静水面、俯视、远景 |
| 网格 + 顶点位移 | 64×64 ~ 128×128 | 需要真实起伏 |
| 细分（Tessellation） | 硬件细分 | 近景需要位移细节 |

小项目直接用 128×128 的静态网格 + 顶点位移，不要碰硬件细分，兼容性更好。

### 2.2 Gerstner 波

四个参数决定一个波：方向 `D`、振幅 `A`、波长 `L`、速度 `S`。

```
ω  = 2π / L                          （波数）
φ  = S · ω                           （相位速度）
Q  = 尖锐度 / (ω · A · 波数总和)       （归一化的 Q，防止自交）

位移.x = Σ  Q · A · D.x · cos( ω · dot(D, xz) + φ · t )
位移.z = Σ  Q · A · D.z · cos( ω · dot(D, xz) + φ · t )
位移.y = Σ      A      · sin( ω · dot(D, xz) + φ · t )
```

- `Q` 控制波峰尖锐度。Q=0 是纯正弦，Q 越大越尖；**Q 过大会让波峰自交**（网格翻面），上限约 0.7
- 波数不是越多越好。**4–8 个**是甜点区：波太多会互相抵消成噪声
- 波长要成几何级数（例如 32 / 16 / 8 / 4 / 2），不要等差数列

典型参数：

| 波 | 波长 | 振幅 | 方向（度） | 速度 |
|---|---|---|---|---|
| 1 | 32 m | 0.5 m | 0 | 1.0 |
| 2 | 16 m | 0.3 m | 45 | 1.2 |
| 3 | 8 m | 0.15 m | -30 | 1.5 |
| 4 | 4 m | 0.08 m | 75 | 1.8 |
| 5 | 2 m | 0.04 m | -60 | 2.2 |

**振幅总和要小于 1/3 的最小波长**，否则相邻波峰互相穿透。

### 2.3 FFT 海洋

用频谱描述海浪能量分布，逆 FFT 得到位移。HDRP 的参数：

```csharp
k_WaterHighBandCount      = 3          // 三个频段
k_PhillipsGravityConstant = 9.81f      // 重力常数
k_WaterMaxChoppinessValue = 2.25f      // 尖锐度上限
k_SwellMaxPatchSize       = 5000 m     // 涌浪
k_SwellMinPatchSize       = 250 m
k_AgitationMaxPatchSize   = 150 m      // 扰动
k_RipplesBandSize         = 10 m       // 细纹
k_SwellMaximumWindSpeed   = 250 km/h
k_AgitationMaximumWindSpeed = 50 km/h
k_RipplesMaxWindSpeed     = 15 km/h
```

三波段的分工：

| 波段 | 管什么 | patch | 风速上限 | 看它的距离 |
|---|---|---|---|---|
| **Swell** | 海平线、大起伏 | 250 m – 5 km | 250 km/h | 永远 |
| **Agitation** | 中尺度浪、近岸碎浪 | 25 – 150 m | 50 km/h | 200 m 内为主 |
| **Ripples** | 表面细纹 | ~10 m | 15 km/h | 30 m 内为主 |

**为什么必须分三段**：单一频谱要么远景没起伏、要么近景是一堆乱七八糟的小波。分段后每段用自己的 patch 尺寸平铺，总位移相加——这是同时兼顾远近的唯一办法。

Phillips 频谱的核心（只给结论，不推导）：

```
P(k) = A · exp(-1/(k·L)²) / k⁴ · |k̂ · ŵ|²
```

- `k` 波矢，`L` 风速相关长度，`ŵ` 风向
- `1/k⁴` 让能量集中在大波长
- `|k̂·ŵ|²` 让浪主要沿风向走

### 2.4 Gerstner 还是 FFT

| | Gerstner | FFT |
|---|---|---|
| 实现成本 | 1 天 | 3–7 天 |
| 运行开销 | 极低（顶点着色器） | 中高（每帧 3 次逆 FFT） |
| 远景质量 | 差（能看到重复） | 好 |
| 风向可实时变 | 可以 | 可以且自然 |
| 适合 | 小水面、池塘、风格化 | 开阔海面 |

**判断依据：摄像机离水面的距离。** 一直在岸边看近处 → Gerstner 够用；要看到海平线 → FFT。

### 2.5 波形层的坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 波峰自交 | 网格翻面、法线全黑 | Q 降到 0.5 以下；或减振幅 |
| 波长等差 | 看起来"一块一块" | 改几何级数 |
| 振幅过大 | 波浪穿模、相机入水 | 总振幅 ≤ 最小波长/3 |
| 位移方向只做 Y | 没有立体感 | XZ 也要位移 |
| 高速相机穿过水面 | 波形跳变 | 位移用世界坐标算，不用物体坐标 |

## 3. 法线：表面细节

### 3.1 这层管什么

**这是全篇最重要的一章。** 水面 90% 的"水感"来自法线，不是几何。

原因：网格再密也做不出厘米级波纹（第 2.1 节），而法线贴图能在同一个三角形里伪造任意高频细节。

### 3.2 贴图

- 格式：**Normal map**（导入设置 Texture Type = Normal，**必须取消 sRGB**）
- 内容：平缓波纹，**不要带高光或颜色信息**（那会让法线计算错误）
- 平铺：**tiling 4–16**。低于 4 近景看出重复；高于 16 远处糊成噪点
- wrap mode：Repeat，且贴图本身要**可无缝平铺**

### 3.3 两层怎么配

| 参数 | 建议 | 原因 |
|---|---|---|
| scale 比 | 1 : 3 ~ 1 : 5 | 大小层次分明 |
| 方向差 | 30° – 60° | 同向叠加成"一道浪"；垂直会互相抵消 |
| 速度比 | **1 : 1.7（绝不要整数比）** | 整数比会周期性重合，出现"呼吸"节拍 |

速度比是新手最常做错的地方。1:2 时两张图每隔一段时间回到同一相对位置，水面就会出现有规律的涨落——一眼看出是循环。

### 3.4 混合

不能直接相加（Z 分量会超 1，归一化后变平）。用 **whiteout blend**：

```
n = normalize( float3( n1.xy + n2.xy, n1.z * n2.z ) )
```

XY 相加保留两个方向的扰动，Z 相乘保证斜率叠加不过度扁平。

### 3.5 距离处理

- 采样时给 **mip bias**（-0.5 ~ +0.5），抵消 tiling 的高频噪点
- 远处降低法线强度（× 0.5–1.0 的距离衰减）
- HDRP 对应参数：

```csharp
startSmoothness        = 0.95    // 近处光滑（roughness 的反面）
endSmoothness          = 0.85    // 远处粗糙
smoothnessFadeStart    = 100 m
smoothnessFadeDistance = 500 m
```

远处不处理 = 满屏闪烁。原因见第 4.4 节。

### 3.6 坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 勾了 sRGB | 像塑料、光照全错 | Texture Type = Normal |
| 两层同速同向 | 拍频、有节奏涨落 | 速度比 1:1.7，方向差 45° |
| tiling 太小 | 近景明显重复 | 提到 8 以上 + 第二层打散 |
| 贴图不可平铺 | 有接缝线 | 用可平铺的贴图 |
| 法线强度拉满 | 远处一片噪点 | 加距离衰减 |

## 4. 高光：太阳反射

### 4.1 为什么是 GGX

水面必须用 GGX，不能用 Blinn-Phong。

**GGX 的尾部更长**——高光从一个亮核向外缓慢衰减。这正是水面碎光"有层次"的来源。Blinn-Phong 的高光是硬切边缘，看起来像塑料球。

法线分布函数：

```
α = roughness²
D = α² / ( π · ( (n·h)² · (α² - 1) + 1 )² )
```

菲涅尔（Schlick 近似）：

```
F = F0 + (1 - F0) · (1 - cosθ)^5
```

水的 `F0 ≈ 0.02`（折射率 1.33）。所以正对水面只反射 2%（看得到水下），掠射角接近 100%（看到天空）。

### 4.2 参数

| 参数 | 区间 | 说明 |
|---|---|---|
| **roughness** | **0.02 – 0.15** | 近 0.02–0.05，远 0.12–0.15 |
| **F0** | **0.02** | 别再调 |
| specular 强度 | 1.0 | 不要靠提亮来"加光"，破坏能量守恒 |
| 高光颜色 | 太阳色 | 除非太阳是白的，否则别用纯白 |

**roughness 低于 0.02 很危险**：高光窄到不足一个像素，开始在屏幕上"跳针"。

物理原因：太阳的角直径约 0.53°，即使完美镜面，反射出的也是约 0.5° 的圆盘而不是一个点。低于这个尺度你在算物理上不存在的东西。

### 4.3 碎点的成因

这是复刻水面必须理解的一段。

**高光碎点 = 法线扰动 × 低 roughness × 像素覆盖面积**

推理链：

1. 一个像素覆盖的水面面积 `A_pixel`
2. 这块水面的法线朝向有一个方差 `σ²`，正比于波浪斜率 × `A_pixel`
3. GGX 高光的角宽度约在 `roughness²` 量级
4. 当 `σ` 超过高光宽度时，像素内的反射方向已经跨越了高光边界——高光在这个像素里"时有时无"
5. 相邻像素的 `σ` 不同，屏幕上就出现一颗颗独立亮点

调控方向：

| 想更碎更闪 | 想更平滑 |
|---|---|
| 提高法线强度 | 降低法线强度 |
| 降低 roughness | 提高 roughness |
| 相机拉近 | 相机拉远 |

**关键推论：远处必须降法线强度 + 升 roughness。** 远处一个像素覆盖的水面大得多，`σ` 天然更大，不补偿就一定闪。

### 4.4 抗闪烁，按性价比排序

| 手段 | 效果 | 代价 |
|---|---|---|
| **roughness 随距离升高** | ★★★★★ | 免费 |
| **法线强度随距离衰减** | ★★★★ | 免费 |
| **法线 mip bias** | ★★★ | 免费 |
| 时间抖动 + TAA | ★★★★ | 中 |
| 屏幕空间滤波 | ★★ | 高 |
| 降分辨率渲染 | ★★★ | 画面糊 |

**前三条免费，先做完再考虑别的。**

### 4.5 坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 只做太阳光，没有环境反射 | 背光面死黑 | 加 Reflection Probe |
| roughness 用常数 | 远景满屏闪 | 距离 fade |
| 高光强度调到 5+ | 过曝、没细节 | 保持 1.0，调太阳强度 |
| 用 Blinn-Phong | 塑料球 | 改 GGX |

## 5. 颜色与深度

### 5.1 四个物理量

| 量 | 作用 | HDRP 默认 |
|---|---|---|
| **折射** | 看水下物的位移 | `refractionColor (0, 0.45, 0.65)`，`maxRefractionDistance 1.0` |
| **吸收** | 越深越暗越蓝 | `absorptionDistance 5.0` 米 |
| **散射** | 浑浊感（次表面散射近似） | `scatteringColor (0, 0.27, 0.23)` |
| **分层散射** | 浪尖比浪腰亮 | `directLightTipScattering 0.6`，`directLightBodyScattering 0.4` |

### 5.2 吸收决定"深浅"

Beer-Lambert：

```
透射率 = exp( -深度 / absorptionDistance )
```

`absorptionDistance = 5` 的含义：**5 米深处光衰减到 37%（1/e）**。

这就是"浅滩见底、深海墨蓝"的分界线。调这个值等于调"海有多深"。

### 5.3 散射决定"水质"

`tipScattering > bodyScattering` 是让浪尖发亮的关键——逆光时浪尖透出的那层绿，就是这一项。

三种水质配方（直接从这四组参数调）：

| 水质 | scatteringColor | absorptionDistance | tip/body |
|---|---|---|---|
| **热带清澈** | (0.0, 0.35, 0.35) | 15–25 m | 0.7 / 0.4 |
| **温带浑绿** | (0.0, 0.27, 0.23) | 5 m | 0.6 / 0.4 |
| **深海墨蓝** | (0.0, 0.10, 0.20) | 2–3 m | 0.4 / 0.3 |

### 5.4 坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 吸收距离太大 | 整个海都是一个颜色，没有深浅 | 降到 5 以内 |
| 没有折射 | 水下物像贴在水面上 | 开屏幕空间折射 |
| 散射色太亮 | 水像牛奶 | 降低 scatteringColor 亮度 |
| 忽略菲涅尔 | 正对水面也全是反射 | 加 Schlick |

## 6. 岸线泡沫

### 6.1 原理：深度差

```
水深 = 水下地形深度 - 水面深度
泡沫 = smoothstep( 阈值上, 阈值下, 水深 )
```

- 水越浅（越靠岸），泡沫越强
- 阈值上下两个数控制泡沫带的宽度

### 6.2 让它不像贴纸

三步：

1. **加两层噪声**（不同速度滚动），扰动泡沫边缘
2. **加时间变化**：泡沫有生命周期（生成 → 变亮 → 消散）
3. **加方向性**：泡沫沿水流方向被拉长（用 flow map）

只做第一步就能去掉"贴纸感"。

### 6.3 参数

| 参数 | 建议 | 说明 |
|---|---|---|
| 泡沫起始深度 | 0.1 – 0.3 m | 越小泡沫越窄 |
| 泡沫终止深度 | 1.0 – 2.0 m | 泡沫带的外边界 |
| 噪声 1 tiling | 4 | 大尺度扰动 |
| 噪声 2 tiling | 12 | 细节 |
| 噪声滚动速度 | 0.05 / 0.12 u/s | 两层速度不同 |
| 泡沫强度 | 0.7 – 1.0 | 太高会过曝 |

### 6.4 坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 深度精度不够 | 泡沫边缘有锯齿 | 深度缓冲用 24 位以上 |
| 透明排序错误 | 泡沫盖住水下物 | 调整渲染队列 |
| 只有深度遮罩没噪声 | 像画上去的白边 | 加噪声 |
| 泡沫不随浪变 | 浪打了泡沫不动 | 泡沫强度乘浪高 |

## 7. 反射与倒影

### 7.1 三种方案

| 方案 | 原理 | 质量 | 开销 |
|---|---|---|---|
| **Reflection Probe** | 预烘焙的立方体贴图 | 中（位置固定） | 极低 |
| **SSR**（屏幕空间反射） | 复用屏幕像素做光追 | 中高（会丢失屏外物） | 高 |
| **Planar Reflection** | 把场景沿水面镜像再渲染一遍 | 最高 | **极高** |

### 7.2 怎么选

| 场景 | 选 |
|---|---|
| 小池塘、静止水面 | Reflection Probe |
| 大水面 + 强反射（要看到山倒影） | SSR + Probe 兜底 |
| 画面里水很重要、硬件够 | Planar |
| 低端机 | 只用 Probe，宁可不反射 |

**Planar Reflection 相当于把整个场景再渲一遍。** 在中低端硬件上是不可接受的，除非你只镜像少数几个物体（用 LayerMask 裁剪）。

### 7.3 菲涅尔与反射强度

反射强度不是常数，随视角变：

```
F = 0.02 + 0.98 · (1 - cosθ)^5
```

- 垂直看水面：反射 2%
- 掠射角（远处）：反射接近 100%

**所以远处的海岸线、远山倒影会非常清楚，近处几乎看不见** —— 这是对的，不要用固定强度去覆盖它。

### 7.4 焦散（Caustics）

水下光斑。三种做法：

| 做法 | 质量 | 开销 |
|---|---|---|
| 贴图投影（最简单） | 低 | 极低 |
| 程序化噪声 + 时间 | 中 | 低 |
| 真实光线追踪 | 高 | 高 |

HDRP 的焦散是预计算网格：

```
k_WaterCausticsMeshResolution = 256   → 256×256 = 65,536 个 quad
```

**这个在低端机上是明显负担，能关就关。**

### 7.5 坑

| 坑 | 表现 | 修法 |
|---|---|---|
| 反射和法线不匹配 | 倒影像贴在玻璃上 | 反射采样也要被法线扰动 |
| 只用 SSR | 屏幕外的东西反射不出来 | 加 Probe 兜底 |
| 反射强度固定 | 近处也全是倒影，假 | 加菲涅尔 |
| Planar 全场景 | 帧率掉一半 | LayerMask 只镜像远处 |

## 8. 组装顺序与验收

### 8.1 按这个顺序做

| 步骤 | 做什么 | 验收 |
|---|---|---|
| 1 | 网格 + 基础材质（单色） | 能看到一片平面 |
| 2 | 加两层法线滚动 | 表面有细节、不重复 |
| 3 | 加 GGX + 菲涅尔 | 有太阳高光 |
| 4 | 加环境反射（Probe） | 暗部不死黑 |
| 5 | roughness 距离 fade | 远景不闪 |
| 6 | 加吸收 + 散射 | 有深浅、有颜色 |
| 7 | 加泡沫 | 岸线有白边 |
| 8 | 加波形位移 | 有大起伏 |

**顺序很重要**：法线必须在高光之前（高光吃法线），反射必须在颜色之前（颜色要用反射结果）。

### 8.2 三条总验收

1. **静止看**：水面有层次，不像贴图
2. **转动相机**：高光在动但不跳针
3. **看远景**：没有一片闪烁的噪点

三条都过，就成。

## 附录 C 常见错误

按踩中概率排序：

1. **法线贴图勾了 sRGB** —— 这是第一号错误，症状是"水面像塑料"
2. **两层法线同速同向** —— 出现有节奏的涨落，一眼假
3. **roughness 用常数** —— 远景满屏闪烁
4. **只做太阳高光，不做环境反射** —— 背光面死黑，像沥青
5. **波形振幅过大** —— 波峰自交，法线全黑
6. **反射强度固定** —— 近处也全是倒影
7. **tiling 太小** —— 近景明显重复
8. **泡沫只有深度遮罩** —— 像画上去的白边
9. **菲涅尔算错**（F0 用 0.04） —— 反射偏强，水显得"金属"
10. **忘了给远处降法线强度** —— 水面像电视雪花
