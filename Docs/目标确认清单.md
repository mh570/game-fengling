# A. 视觉基础线（像素风）

## A1. 视口缩放（像素化）

- **要求**：整个画面以**可调的缩放比例**渲染（约 0.5~1.0），再点采样放大到屏幕
- **证据**：04 视频面板明确写着 `视口缩放 x0.56 / x0.69 / x1.00`
- **验收**：降低缩放时，画面出现明显像素格；提高时恢复清晰
- **状态**：❌ 未做

## A2. 贴图风格

- **要求**：所有贴图是**低分辨率像素画**，采样用点采样（不模糊）
- **证据**：05/06/07 的草地、石头、树冠都能看到像素块
- **验收**：近看能看出像素块边界
- **状态**：❌ 未做

## A3. 调色板

- **要求**：有限、低饱和、偏冷绿
- **证据**：全部视频一致
- **验收**：截图取色，颜色落在这几组内
- **状态**：🟡 规范已写（`analysis/05`），未强制

## A4. 对比度

- **要求**：低对比、高环境光，不出现死黑/过曝
- **证据**：全部视频
- **状态**：🟡 部分（雾已修）
