# 树的素材制作指南

**目标**：做出参考视频里那种树——**许多小叶片叠成的密冠**，不是几个球。

---

# 一、先明确目标特征

对照视频里的树：

| 部位 | 要求 |
|---|---|
| **树干** | 细长、略锥形、深棕近黑（`#3A2A20`），高度约占全树 40~50% |
| **树冠** | **几十到上百个小叶片/小平面**堆成一个圆润但不规则的团 |
| **单叶片尺寸** | 约树冠直径的 1/10 ~ 1/15（小） |
| **树冠直径** | 高度的 70~100%（宽） |
| **叶片朝向** | 各方向随机（不是都朝外） |
| **颜色** | 深绿 `#2E4A28` 到亮绿 `#6E9448`，随机分配 |

---

# 二、工具选择（都免费）

| 工具 | 难度 | 适合 | 下载 |
|---|---|---|---|
| **Tree It** | ★☆☆ 最简单 | 独立小软件，专门做低模树，拖滑块就出树 | 搜 "Tree It tree generator" |
| **Blender + Sapling Tree Gen** | ★★☆ 灵活 | 内置插件，参数极多，能精确控制叶簇 | blender.org（免费） |
| **Blender 手工** | ★★★ 最自由 | 完全可控，但慢 | 同上 |

**推荐先用 Tree It**——它专门做游戏用的低模树，5 分钟就能出一棵。

---

# 三、Tree It 的步骤（最简单）

1. 打开 Tree It → `File > New Tree`
2. **Trunk 标签**
   - Height：20~30
   - Radius：0.8~1.2
   - Taper（锥度）：0.5~0.7（上细下粗）
3. **Branches 标签**
   - Number：3~5（少一点，视频里的树分枝不明显）
   - Length：树高的 30%
   - Angle：40~60°
4. **Leaves 标签** ← **关键**
   - **Leaf Type：`Cross` 或 `Quad`**（十字或单片）
   - **Number of Leaves：500~1500**（要很多！）
   - Leaf Size：0.3~0.6（小）
   - Distribution：`Sphere`（球形分布）
   - Sphere Radius：树冠半径
5. 调 **Random Seed** 多试几次，挑最好看的
6. `File > Export > FBX`

---

# 四、Blender + Sapling 的步骤（更可控）

1. Blender → `Edit > Preferences > Add-ons` → 搜 **Sapling Tree Gen** → 打勾启用
2. `Add > Curve > Sapling Tree Gen`
3. 在左下角面板调参数：
   ```
   Geometry:
      Bevel Resolution: 4
      Curve Resolution: 4
   Branching:
      Levels: 2 或 3        ← 不要太多层
      Branches: 6~10
   Leaves:
      Show Leaves: ✔
      Leaves: 400~1200      ← 关键：要多
      Leaf Size: 0.35
      Leaf Shape: 用默认六边形，或换成自己的叶片贴图
   ```
4. **换成卡片叶片**（视频那种）：
   - 在 `Leaves > Leaf Object` 里选一个 plane
   - 给 plane 加叶片贴图（PNG + alpha）
5. **导出**：
   `File > Export > FBX`，勾选 `Selected Objects`，`Apply Modifiers`

---

# 五、叶片贴图怎么做

**最简单的做法：程序生成**

用 Aseprite（免费）或任何画图软件，画一个 **32×32** 的叶片簇：

```
底色：透明
画 5~8 个小椭圆（不规则分布）
颜色：深绿 → 中绿 随机
边缘：硬边（像素风，不要抗锯齿）
导出 PNG（带 alpha）
```

**或者**用现成的 CC0 叶片贴图：
- <https://opengameart.org/art-search-advanced?keys=leaf+texture>
- 搜索 "foliage texture alpha"

# 六、导出设置（Godot 能直接用）

| 项 | 值 |
|---|---|
| 格式 | **FBX**（Godot 4.4 能导入 FBX，需要 FBX2glTF）或 **glTF 2.0 (.glb)** |
| 推荐 | **.glb**（Godot 原生支持，不用转换） |
| 缩放 | 1 单位 = 1 米 |
| 原点 | **树根在 (0,0,0)** |
| Y 轴向上 | ✔ |
| 应用变换 | `Ctrl+A > All Transforms` |

**Blender 导出 glTF 的设置**：
```
File > Export > glTF 2.0
  Format: glTF Binary (.glb)
  Include: Selected Objects
  Transform: +Y Up ✔
  Geometry: Apply Modifiers ✔
```

# 八、验收标准（对着视频看）

做好后，从**俯视 45~60°、距离 20~40m** 看：

| 检查项 | 通过标准 |
|---|---|
| 树冠轮廓 | **毛糙、不规则**，不是光滑圆 |
| 能看到叶片吗 | **能看出是一片片叶子**，不是一整块 |
| 明暗 | 有**深有浅**，不是单色 |
| 像葡萄吗 | **不像**（苹果树那种一堆圆球就是葡萄） |
| 树干 | 细、深棕、明显 |
