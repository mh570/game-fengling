# 参考风格分析：俯视贴图水（Isometric Stylized Water）

> 目标图：浮岛 + 浅蓝半透明水 + 点状岸线泡沫 + 俯视等距视角
> 参考：`godot-demo-projects/compute/texture`、t3ssel8r 的风格化水体思路

---

## 1. 先回答"为什么还是一个人的视角"

因为**我把相机做成跟随角色的第三人称**，这是动作/RPG 的机位。而参考图是**地图视角**：

```
参考图：相机在场景上方，俯角 60–90°，画面里没有"角色"，只有地形
我们的：相机挂在角色后上方，画面中心永远是那个角色
```

两者不是调参数能转换的，是**相机控制器类型不同**。要做参考图那种，需要：

- 删掉 `ThirdPersonCamera`、`PlayerMotor` 的跟随逻辑
- 换成 `TopDownCamera`：正交投影 或 高远透视，固定俯角，可平移缩放（像 RTS/模拟经营）
- 角色可以保留（缩小成一个小点），也可以先不要

---

## 2. 参考图拆解：8 个图层

| # | 图层 | 图里看到的现象 | 技术本质 |
|---|---|---|---|
| 1 | **相机** | 等距俯视，没有消失点夸张 | 正交投影或 50°+ 俯角透视 |
| 2 | **水体色** | 极浅的粉蓝，几乎奶白 | 高 ambient、低饱和、无高光 |
| 3 | **透明度** | 能看见水下地形、石头、鱼 | alpha 随深度衰减 |
| 4 | **深度梯度** | 浅处更淡，深处略深 | 深度 → 颜色 ramp |
| 5 | **岸线泡沫** | **点状虚线**，不是连续白带 | 深度阈值 × 高频点状掩码 |
| 6 | **水下地形** | 岛体向下延伸成深色柱体 | 地形本身有水下部分 + 水下染色 |
| 7 | **光照** | 没有强阴影、没有镜面 | 近乎纯漫反射 + 高环境光 |
| 8 | **调色** | 整体偏亮、低对比、轻微泛光 | Bloom + 提亮 + 降饱和 |

---

## 3. 每一层怎么做

### 3.1 相机（最关键）

```csharp
// 正交相机：等距风格的核心，远处不会变小
cam.orthographic = true;
cam.orthographicSize = 40;      // 视野高度（米）
cam.transform.rotation = Quaternion.Euler(55f, 45f, 0f);  // 俯角 + 旋转
cam.transform.position = target + new Vector3(0, 60, 0);
```

参考图是**正交**的：岛与岛之间大小一致，没有透视收缩。这是等距风格的第一要素。

### 3.2 水体色：从"墨绿"改成"奶蓝"

| 现在的值 | 参考图的值 |
|---|---|
| shallow `(0.55,0.85,0.85)` | `(0.72,0.90,0.92)` 更淡 |
| deep `(0.02,0.18,0.30)` | `(0.10,0.38,0.52)` 更浅、更饱和 |
| absorption 4 m | **8–12 m**（水"浅"是风格，不是物理） |
| 有 GGX 高光 | **几乎去掉**（高光是写实向的） |

**风格化水的核心是"牺牲物理换可读性"**：不要菲涅尔、不要太阳碎光，让水看起来像一层半透明的玻璃纸。

### 3.3 透明度：alpha 按深度，但整体调低

```hlsl
alpha = saturate(depth / _FadeDistance) * _OpacityScale;  // _OpacityScale ≈ 0.65
```
参考图里**最深处也只有 0.7 左右的不透明**，因为要能看到鱼。

### 3.4 点状岸线泡沫（重点）

参考图的泡沫不是白带，是**虚线点阵**：

```hlsl
float edge   = 1.0 - saturate(depth / _FoamWidth);       // 岸线附近的带
float dots   = step(0.55, noise(worldXZ * 8.0));         // 高频点状掩码
float foam   = edge * dots;
```

关键在于 **`step` 而不是 `smoothstep`**：硬阈值切出离散的点，才有"点线"感。
再叠一层低频噪声控制点的疏密，避免均匀。

### 3.5 水下地形

参考图里每个岛都是一个**向下延伸的柱体**，水下部分变暗变蓝：

```hlsl
if (worldPos.y < waterLevel)
    color *= float3(0.55, 0.75, 0.85);   // 水下染色
```
这要求地形网格**真的往水面以下延伸**（我们的 `CoastTerrain` 已经做到了：海底在 -8 m）。

### 3.6 光照与调色

- 关掉阴影或极弱阴影
- 环境光拉高（Skybox ambient intensity 1.5+）
- Bloom：阈值 1.0，强度 0.3（轻微泛光）
- 颜色分级：提亮 + 降饱和 + 稍微偏青

## 4. 和当前实现的差距（逐条）

| 项 | 当前 | 目标 | 差多少 |
|---|---|---|---|
| 相机 | 第三人称跟随角色 | 正交俯视 | **重做** |
| 水体色 | 深蓝绿 + 高光 | 奶蓝 + 无高光 | 改参数 + 删高光 |
| 透明 | 有，但深水太黑 | 整体更透 | 调 alpha |
| 泡沫 | 连续白带 | 点状虚线 | **重写** |
| 水下地形 | 有地形，但水下没染色 | 水下变暗变蓝 | 加染色 |
| 阴影 | 有硬阴影 | 几乎无阴影 | 关掉 |
| 调色 | 无 | Bloom + 提亮 | 加后处理 |

## 5. 改造计划（按依赖顺序）

1. **相机**：`TopDownCamera`，正交，俯角 55°，平移/缩放
2. **水材质转向风格化**：删高光、改奶蓝、alpha 调整
3. **泡沫改点状**：`step` + 高频噪声
4. **水下染色**：地形 shader 或水 shader 里按 y 染色
5. **调色**：Volume 加 Bloom + 颜色分级，关阴影
6. **场景**：把海岸换成"浮岛"（可选，先不做）

## 6. 关于你给的两个参考

### godot-demo-projects/compute/texture
这是**用 compute shader 生成/更新纹理**的官方 demo。对我们的用处：
- 想要"水面涟漪随时间演化"时，可以用 compute shader 每帧更新一张高度/法线纹理
- 但我们当前是 CPU 端 Gerstner + 静态法线贴图，**不需要 compute**
- 真正需要它的场景：交互涟漪（鱼、船、落水物）—— 那是下一步

### t3ssel8r
以"painterly / retro 风格化渲染"出名，核心思路和我们参考图一致：
- **牺牲物理正确性换可读性**
- 高环境光 + 低对比 + 手绘感
- 水面用"色阶"而不是连续渐变

对我们最直接的启发：**水的颜色要做成有限几档色阶**（posterize），而不是连续插值。

```hlsl
float depthStep = floor(saturate(depth / _FadeDistance) * 4.0) / 4.0;  // 4 档色阶
float3 waterColor = lerp(_ShallowColor.rgb, _DeepColor.rgb, depthStep);
```

## 7. 结论

参考图是**风格化等距水**，和我们现在做的**写实第一/第三人称水**是两条路线。

要变成参考图那样，需要动的是：
1. 相机（正交俯视）— 最大改动
2. 水的审美（去高光、改奶蓝、色阶化）— 参数级
3. 泡沫（点状）— 局部重写
4. 后期（Bloom + 调色）— 配置级

**不是调参能到位的，得换赛道。** 确认要走这条路线，我就按第 5 节重做。
