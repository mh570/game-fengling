# S2 宏观形体 · 第一版

**日期**：2026-11-22
**状态**：第一版 V0–V5 + 第二轮 V8/V9 已出；仍偏“云朵”，G2 未通过
**规则**：只看剪影/叶团/树干，不看叶片、颜色、光照。

## 第一版

| ID | 叶团 | 说明 |
|---|---|---|
| V0 | 4 | 宽扁，顶部一个凸起 |
| V1 | 5 | 更宽，顶部两个凸起（用户选中） |
| V2 | 3 | 紧凑 |
| V3 | 4 | 偏高，作为对照 |
| V4 | 5 | 平底，前后有叶团 |
| V5 | 4 | 不对称，右侧更大（用户选中） |

## 第二轮

| ID | 来源 | 改动 | 结果 |
|---|---|---|---|
| V8 | V1 | 加底部裙摆、缩小侧叶团 | 侧叶团仍像圆片，整体仍“云朵” |
| V9 | V5 | 加底部裙摆、保留不对称 | 同上 |

**结论**：独立椭球拼轮廓会留下“完整圆片”的侧叶团；下一轮改用“一个主椭球 + 表面浅凸起”的连续曲面，或对独立球做更强的嵌入/缺口。

## 第三轮：连续曲面

用户给了参考：大而连通的圆润叶团，不是独立球。

| ID | 做法 | 结果 |
|---|---|---|
| V10 | 一个连通网格 + 6 个高斯凸起，对称宽伞 | 叶团连通、有柔和凹槽；太对称、太蘑菇 |
| V11 | 同上，偏冠/右侧更大 | 有偏冠，但仍偏锥形 |

**结论**：方向对了；下一步以 V11 为底，压扁/加宽/加右冠，出 V12，目标 T2 的宽伞 + 偏冠。

## 第四轮：径向强凸起（失败）

V12 把高斯凸起加窄、加高，试图做出参考里 5–6 个圆润叶团；结果径向位移产生**海星/花形尖角**，不是圆叶团。

**结论**：径向连续曲面不适合做“多个圆球融合”。正确路线是 **metaball / 隐式曲面 + 等值面网格（marching tetrahedra）**，或 DCC 雕刻。V12 放弃。
