# S3 · 叶簇第一版

**日期**：2026-11-23
**状态**：🟡 第一版；G3 未通过
**规则**：只评价叶簇单元，不评价法线/AO/场景；S4 再处理光影。

## 第一版参数

- 60 张 alpha cutout 卡片；
- 0.80–1.10m；
- 256×256 叶簇贴图（14 片叶 + 2 根枝）；
- 卡片贴在 V17 canopy 表面，切向朝向，随机滚转；
- 浅绿/深绿按法线+高度混合。

## 结果

- T1/T2 都能看到叶簇，但**覆盖率明显不足**，仍像“绿色球上撒了几片叶子”；
- 贴图内部叶团偏小、alpha 稀疏；
- 卡片切向贴在球面上，边缘卡片被球面遮住一部分。

## 下一步

1. 贴图改成“中央实心团块 + 边缘叶片”的叶簇，alpha 覆盖 ≥65%；
2. 卡片数量 60 → 80–90，或加第二层；
3. 卡片尺寸略增到 0.9–1.2m；
4. 再出 B3，目标：100% 视图数不出单片叶、冠内覆盖 85–95%。
