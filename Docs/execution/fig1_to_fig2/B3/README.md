**日期**：2026-11-23

## v2 参数

- 85 张卡片（v1 为 60）；
- 0.90–1.20m；
- 贴图：5 个中央实心团 + 12 片边缘叶 + 2 根枝，alpha 覆盖明显提高；
- 仍切向贴 V17 表面。

## 结果

- 比 v1 密，但仍能看到大片深绿壳，覆盖率约 50–60%，未到 85–95%；
- 卡片像“圆斑”，还没形成连续叶簇层；
- 叶片个体在 T1/T2 已基本不可辨。

## 结论

单层卡片在 7m 冠幅上覆盖不足。下一步二选一：

1. 加第二层（再 80 张，内外两层），或总数 150–180；
2. 给 canopy 壳加叶簇纹理底衬，卡片只负责轮廓/破边。

建议先做 **1+2**：壳上叶簇纹理打底 + 160 张卡片，既保覆盖又保轮廓。
