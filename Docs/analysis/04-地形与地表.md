# 04 · 地形与地表

**分析日期**：2026-11-21
**模块**：L3 地形与地表
**为什么先做这个**：这是"环境丑"最直观的来源——大片纯色平面。

---

# 一、现状

| 项 | 我们的做法 |
|---|---|
| 地形生成 | `CoastTerrain`：程序化高度图（`CoastHeightMap_*.asset`） |
| 地表材质 | **单一 `Fengling/Lit` 材质**，一个基色 |
| 纹理 | 无（纯色） |
| 植被 | 无（只有 Props 里零散摆件） |
| 细节 | 无 |

## 观感问题（截图已证实）

1. **整片橄榄褐，没有材质变化**——沙地、草地、岩石全是同一个颜色
2. **没有细节纹理**——近距离看是纯色块
3. **没有植被**——空旷、没有尺度参照
4. **云影是程序化噪声**，与天上云无关，叠上去更像"脏斑"

---

# 二、外部方案

## 方案 A：Splat / 混合图层（最主流）

**做法**：一张 splat 贴图（RGBA 通道）控制沙/草/岩/泥的混合权重，shader 采样多套 albedo+normal。

**参考**：
- Unity 内置 Terrain 的 TerrainLit 就是这套
- [Stylized-Terrain-URP](https://github.com/BradFitz66/Stylized-Terrain-URP)：风格化版本，带三平面映射

| 成本 | 效果 |
|---|---|
| 中（要做 splat 数据 + 4 套纹理） | 立刻从"色块"变成"地表" |

## 方案 B：三平面映射（Triplanar）

**做法**：按法线方向混合三个投影轴，避免 UV 拉伸，适合程序化地形/岩壁。

| 成本 | 效果 |
|---|---|
| 低（纯 shader） | 陡坡不会出现拉丝，岩石感强 |

## 方案 C：程序化细节叠加

**做法**：在基础色上叠多层噪声（大中小尺度），不需要纹理资源。

| 成本 | 效果 |
|---|---|
| 极低 | 有变化但仍是"抽象色块"，不如真实纹理 |

## 方案 D：草与散布物

**做法**：
- 草：GPU instancing + 风动 shader（[Stylized Grass Shader](https://github.com/VKev/Unity-URP-Shaders-Code)）
- 石头/树：程序化撒点 + LOD

**参考**：[Elijahtab/Terrain-Generator](https://github.com/Elijahtab/Terrain-Generator)（Perlin + 植被散布，策略游戏向）

---

# 三、差距

| 项 | 我们 | 主流做法 | 差距性质 |
|---|---|---|---|
| 地表颜色 | 单一基色 | splat 混合 4+ 层 | **缺功能** |
| 法线细节 | 无 | normal map / 三平面 | **缺功能** |
| 植被 | 无 | 草 + 撒点 | **缺功能** |
| 云影 | 程序化噪声 | 从天上的云投影 | **架构错**（两套独立数学） |
| 地形网格 | 高度图 | 高度图（一致） | 无差距 |

**结论：地形这块不是"调参能解决"的，是缺了整整一个内容层。**

---

# 四、迭代计划（建议顺序）

## 第 1 步：让地表有材质变化（1 天）

1. `FenglingLit` 加三平面映射（triplanar）采样
2. 至少 3 套参数化地表：沙 / 草 / 岩（可先用程序化噪声，不依赖纹理资源）
3. 按坡度自动混合：平地沙/草，陡坡岩

**验证**：截图对比，同一机位前后各一张。

## 第 2 步：云影从天上的云来（0.5 天）

1. 体积云 pass 额外输出一张**俯视密度图**（或直接用云密度函数按世界 XZ 采样）
2. 地面 shader 采样它，替换现在的程序化噪声
3. 这样影子才会跟着云走

**验证**：改云的覆盖度，地面暗斑应同步变化。

## 第 3 步：草与散布物（2 天）

1. GPU instancing 草，随风摆动
2. 石头/灌木按高度和坡度撒点

**验证**：截图看密度和尺度是否自然。
