# 地形与画面"好看"的原理

**日期**：2026-11-21
**用途**：不是记流程，而是记**为什么好看**。流程会过时，原理不会。
**来源**：见文末

---

# 一、地形层面：4 个原理

## P1. 高度混合（Height-Based Blending）★ 最重要

> "用高度图把上层材料'推'到下层的上面，形成自然过渡——例如**岩石从草丛里突出来**。"
> —— [AstraWeave PBR-F 设计文档](https://github.com/lazyxeon/AstraWeave/blob/main/docs/pbr/PBR_F_DESIGN.md)

**纯 splatmap 的问题**：两种材质按权重线性混合，边界是"糊"的，像贴纸。

**高度混合的做法**：
```
final = blend(A, B, weight + bias * heightA)
```
让"高"的那一层在交界处先露出来 → 岩石边缘不规则地刺穿草地，**像真的**。

**对我们的意义**：
我们现在顶点色是**按高度线性插值**——所以过渡是一条平直的渐变带。
应该改成：**交界处用噪声决定谁在上**，形成不规则的锯齿状边界。

这条不但对地形有用，对**草地与沙地交界、岩石与草地交界**都成立。

## P2. 三平面映射（Triplanar Mapping）

陡坡上贴图会被拉伸（因为 UV 是平面投影的）。
三平面用 X/Y/Z 三个方向的投影按法线加权混合 → 陡坡也不拉伸。

**对我们的意义**：我们暂时不用贴图（顶点色），但以后加贴图时必须考虑。

## P3. 色彩方案的统一性

> "早期就建立**统一的调色板**：天空、石头、草、植被各定一种一致的颜色，
> 保证不同元素在视觉上是一套的。"
> —— [Making Beautiful 3D Games](https://gameindustrylibrary.com/documents/making-beautiful-3d-games-is-easier-than-you-think)

**原理**：人眼判断"这是一个世界"靠的是**色彩一致性**，不是模型精度。

**对我们的意义**：`05-风格化美术规范.md` 的调色板要**强制**执行，不能随意加色。

## P4. 植被铺满 > 地形细节

> "限制地形只使用 3~4 种主贴图。"

**原理**：地面被植物盖住时，人**根本看不到**地形细节。
所以资源应该优先给植被，而不是地形。

**对我们的意义**：我们现在"裸地形"，无论怎么调都不可能像。

# 二、画面层面：4 个原理

## P5. 阴影不能是纯黑 ★

> "阴影或高光的颜色**不该只是加黑或加白**，那会让物体看起来**没有生命**。"
> "光在材质里弹射后从另一侧穿出，会让饱和度上升。"
> —— [Theseus 论文：游戏视觉风格](https://www.theseus.fi/bitstream/handle/10024/101918/Thesis_LauraOravakangas.pdf)

**这解释了我们之前的一个发现**：参考视频里树影是**深绿色**而不是黑色。

**原理**：阴影区仍然有**环境光的颜色**。纯黑阴影 = 物体死亡。

**对我们的意义**：
- 阴影颜色应该 = 环境色 × 强度，而不是 black × alpha
- 我们的 `PlayerBlobShadow` 现在是黑色椭圆 → 应该是深绿

## P6. 大气透视（Atmospheric Perspective）

远处的物体：**降低对比度 + 偏向天空色**。

> "后处理、**雾**和镜头光晕，对营造**深度、氛围和尺度感**是必需的。"

**原理**：现实里空气散射让远景发灰发蓝。这是人脑判断"远"的主要线索。

**对我们的意义**：我们已有距离分级雾，但**雾色应该等于天空色**（现在可能不一致）。

## P7. 颜色校正（Color Grading）

> "通过精细的颜色校正，每一束光都被调过，塑造出**丰盛感**。"
> —— [Ubisoft: Every Ray of Light Tells a Story](https://www.ubisoft.com/en-us/company/how-we-make-games/overview/articles/passion-meets-craft-every-ray-of-light-tells-a-story)

**原理**：原始渲染的颜色是"物理正确"的，但不一定"好看"。
颜色校正做的是：**统一色温、提饱和、压暗部、加胶片感**。

**对我们的意义**：我们**完全没有颜色校正**。这是"看起来业余"的一大原因。

## P8. 焦点与细节密度

> "光影对饱和度影响很大——很亮或很暗的区域，颜色会接近白或黑。"

**原理**：亮部和暗部都会"吃掉"颜色。所以**中间调才有色彩**。
画面要避免大面积过曝/死黑。

**对我们的意义**：我们之前的截图画面对比度太低、整体发白——正好违反这条。

# 三、把原理映射到我们的具体改动

| 原理 | 具体改动 | 优先级 |
|---|---|---|
| **P1 高度混合** | 顶点色交界加入噪声，让岩石不规则刺穿草地 | **高** |
| **P5 阴影有颜色** | 阴影/暗部乘环境色（深绿），不用黑色 | **高** |
| **P7 颜色校正** | 加一个 post pass：饱和度 + 对比度 + 色温 | **高** |
| **P6 大气透视** | 雾色 = 天空色 | 中 |
| **P8 避免过曝** | 压曝光，让中间调占主导 | 中 |
| **P4 植被铺满** | 草 + 树 | 高（工作量大） |
| P2 三平面 | 以后加贴图时 | 低 |
| P3 色彩统一 | 已有规范，执行 | 持续 |

# 四、最重要的一条

> **"好看"不是把每个东西做得更精细，而是让所有东西看起来属于同一个世界。**

具体表现为：
1. 统一的色彩范围
2. 阴影和暗部有颜色
3. 远处的东西化入空气
4. 地面被植物盖住

**这四条没有一个需要高精度模型。** 我们缺的不是技术，是这四条。
