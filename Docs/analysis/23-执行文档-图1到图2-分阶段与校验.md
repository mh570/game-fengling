## 1. 执行体系：每次校验怎么做

### 1.1 三级校验

| 级别 | 名称 | 何时做 | 谁做 | 失败后果 |
|---|---|---|---|---|
| **C** | 步骤校验（Check） | 每个步骤完成后立即做 | 执行者 | 不修复不进下一步 |
| **G** | 阶段门禁（Gate） | 每个阶段结束时 | 执行者 + 用户 | 回退到本阶段入口基线 Bx |
| **A** | 最终验收（Acceptance） | S7 | 用户 + 技术复核 | 不发布，回到失败项所在阶段 |

**规则**：
1. 每个步骤必须有 **C 编号**，且能指回方案条款；
2. 每个阶段必须有 **G 编号**，且能指回本阶段所有 C；
3. 没有截图/指标/日志的“通过”不算通过；
4. C 失败只修本步；G 失败回退本阶段 Bx；A 失败回到对应阶段，不直接改最终参数。

### 1.2 每次校验的四件套

| 件 | 内容 | 示例 |
|---|---|---|
| 方案条款 | 这一步对应方案哪一节 | `方案 §4 阶段2` |
| 校验 ID | Cx.y / Gx / A.x | `C3.2` |
| 证据 | 截图、CSV、日志、场景文件 | `B3/B3_640.png` |
| 结论 | 通过 / 不通过 + 偏差 + 处理 | `通过；覆盖率 91%` |

> **没有证据 = 没做。没有方案条款 = 不许新增校验项。**

### 1.3 基线制度（每个阶段都有 Bx）

**基线 = 一张锁定图 + 一组指标 + 一个可复现的相机/种子/分辨率。**

| 基线 | 内容 | 关键指标 / 通过线 | 用于阶段 | 回退点 |
|---|---|---|---|---|
| **B0** | 当前树 + 当前像素化 | 单叶 8–16px；edge 15.4%；色相 94°；蛋形冠 | S0 入口 | S1 失败回 B0 |
| **B1** | 图2 取景，无新模型 | 冠宽 120–150% 画幅；树干 25–35% | S1 出口 | S2 失败回 B1 |
| **B2** | 宏观形体 clay（无叶） | 3–5 叶团；≥2 个 >0.4m 凹槽；树干 30–40% | S2 出口 | S3 失败回 B2 |
| **B3** | 叶簇卡片，旧光照 | 35–60 张卡；单叶不可辨；覆盖 85–95% | S3 出口 | S4 失败回 B3 |
| **B4** | 叶团法线 + AO + 投影 | 冠顶/冠底 L 差 25–35%；无逐叶暗点 | S4 出口 | S5 失败回 B4 |
| **B5** | 场景 + 雾 + 调色 | 5 点采样 ΔE ≤6；远景对比 −20–30% | S5 出口 | S6 失败回 B5 |
| **B6** | 640×360 + OKLab 量化 | edge 1–3%；L 115–125；hue 110–125 | S6 出口 | S7 失败回 B6 |
| **B7** | 最终验收包 | A1–A10 全过；盲评 ≥4/5 | S7 出口 | 发布 |

**基线锁规则**：
- 每阶段通过后，Bx 目录只读，不再改；
- 任何参数变化都生成新版本（`Bx_v2`），不能覆盖旧基线；
- 每次进入新阶段，先重渲一次上一阶段 Bx；若 pixel diff >1%，先查环境（Unity 版本/后处理/相机/种子），再继续。

### 1.4 证据规范

**目录**：

```
Docs/execution/fig1_to_fig2/
  B0/  baseline.json  B0_3d_1024.png  B0_640.png  target_620.png  metrics.csv
  B1/  B1_640.png  camera.json  compare.png  metrics.csv
  ...
  B7/  acceptance.xlsx  final_1080p.png  compare_target.png  perf.csv
```

**截图要求**：
- 固定相机、固定 seed、固定分辨率、固定后处理；
- 每张图渲 **3 帧**，取第 3 帧；3 帧差异 <1% 才有效；
- 同时保存 **100% 视图**和 **3× 放大视图**（用于看像素块）；
- 文件名含阶段、视角、版本：`B3_640_front_v1.png`；
- 所有截图带 `baseline.json` 里记录的 settings hash。

**指标 CSV 至少包含**：
`edge_density, grad_mean, L_p5, L_p50, L_p95, hue_mean, palette_levels, canopy_coverage, trunk_ratio, silhouette_lobes, notch_depth_max`

### 1.5 变更控制

任何偏离方案文档的改动，必须开 **CR（Change Request）**：

```
CR-YYYYMMDD-NN
阶段 / 步骤：
变更前：
变更后：
原因：
影响的校验项：
回退方案：
批准人：
```

**规则**：
- 没有 CR 的参数改动，视为违规，必须回退；
- 目标图（图2）在 G0 后不得更换；确需更换，版本升到 v2 并重跑 G0；
- G5 后不得再改目标裁切或构图。

### 1.6 停止 / 回退规则

| 触发 | 动作 |
|---|---|
| 单个 C 失败 | 本步内修复；不修复不进下一步 |
| G 失败 1 次 | 回退本阶段入口 Bx，记录偏差，重做失败项 |
| G 失败 2 次 | 暂停该阶段；回看方案和基线，必要时开 CR |
| 连续 2 个阶段超时 | 砍范围（先保 S0–S4），不降门禁 |
| 目标图/裁切被改 | 立即停止；回到 G0 重新锁目标 |

### C. 校验方法细节

- **边缘密度**：Sobel 亮度梯度 >12 记为边缘；边缘像素 / 有效树冠像素；目标 1–3%。
- **亮度**：Rec.709 `L = 0.2126R + 0.7152G + 0.0722B`；冠顶/冠底各取 20×20 区域中位值。
- **色相**：HSV 色相加权平均（按饱和度加权）；目标 110–125°。
- **ΔE**：CIEDE2000；5 点采样（冠顶/冠中/冠底/树干/背景）。
- **剪影**：64×64 二值图；人工数凸起/凹槽；凹槽深度用世界坐标测。
- **覆盖率**：树冠 bbox 内非背景像素 / bbox 面积；目标 85–95%。
- **盲评**：同一裁切、同一尺寸，A/B 随机左右；5 组；至少 4 组选“更像图2”。
