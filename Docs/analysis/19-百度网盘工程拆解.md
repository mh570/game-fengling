# 三、`Leaf.shadergraph` 的节点结构（决定性发现）

从节点名反推：

```
① Camera → Subtract → Cross Product → Matrix Construction
   → 叶片【朝向相机 billboard】

② normal（MaterialPropertyBlock 传入）→ VertexDescription.Normal
   → 顶点法线 = 球面法线

③ Dot Product(N, L) → Remap → Clamp → Sample Gradient → BaseColor
   → 颜色来自【渐变贴图按 N·L 采样】

④ Flipbook + Time + Speed + speedOffset → 风动画
⑤ Sample Texture 2D → Alpha → AlphaClipThreshold
```

**其他节点**：`Main Light`、`Main Light Shadows`、`Transform`、`Multiply`、`Add`、`Normalize`、`Position`

# 五、必须照做的三条（按影响排序）

## ① 叶片 billboard 朝相机（已实现 ✅）

顶点着色器里围绕卡片中心重建位置：
```hlsl
float3 centerOS = IN.uv2.xyz;              // 生成器把卡片中心写进 UV2
float3 corner   = IN.positionOS.xyz - centerOS;
float3 centerWS = TransformObjectToWorld(centerOS);
float3 toCam    = normalize(_WorldSpaceCameraPos - centerWS);
// 柱面 billboard（只绕 Y 轴）
float3 rightV = normalize(cross(float3(0,1,0), toCam));
float3 posWS  = centerWS + rightV * corner.x + float3(0,1,0) * corner.y + toCam * corner.z;
```

## ② 叶片位置改成「形状网格顶点」

不是随机球面撒点，而是**遍历 ShapeMesh 的顶点**，每个顶点按密度决定是否长叶子。

**天然均匀、天然贴合形状**——这就是 t3ssel8r 说的 "evenly-distributed"。

## ③ 颜色改成渐变贴图采样

```hlsl
float ndl = saturate(dot(N, L) * 0.5 + 0.5);
float3 col = SAMPLE_TEXTURE2D(_GradientTex, sampler, float2(ndl, 0.5)).rgb;
```

比 `lerp(shadow, highlight, q)` 更平滑、可任意定制色阶。
