# 差距与迭代路线

**日期**：2026-11-21
**用途**：把分析结论汇总成可执行顺序。所有"别人怎么做"的细节见各模块文档。

---

# 一、一句话结论

> **环境丑不是因为某个参数没调好，是因为缺了三个内容层：地表材质、植被、云的投影。**
> 而这三个层之所以迟迟做不出来，是因为底层管线（自建 SRP）让我们每加一样东西都要自己接一遍。

| # | 模块 | 差距 | 性质 | 优先级 |
|---|---|---|---|---|
| 1 | 地形 | 单一色块，无材质分层 | 缺功能 | **P0** |

| 9 | 后处理 | 手写 Blit，无标准链 | 缺功能 | P2 |

# 三、执行顺序

## P0-A：地表材质分层（1 天）

- 三平面映射
- 沙 / 草 / 岩三层，按坡度混合
- 验证：同机位截图对比

## P0-B：云影改为从天上的云来（0.5 天）

- 体积云输出俯视密度
- 地面采样它
- 验证：调云覆盖度，地面暗斑同步变

## P1-A：水体细节（1 天）

- 参考 [Crest](https://github.com/wave-harmonic/crest)：波纹法线、菲涅尔、折射
- 我们已有平面反射和波场，缺的是**法线细节和菲涅尔**
- 验证：截图看 12:00 和 18:00

## P1-B：植被撒点（2 天）

- 草（instancing）+ 石头/灌木（撒点）
- 验证：密度、尺度、远处 LOD

## P2：管线世代（3-5 天）

- 见 `01-框架与管线.md`
- 和"迁 URP"这个战略决策绑定，先决策再动手

# 四、必须先做的战略决策

**自建 SRP 还是迁 URP？**

这件事不解决，P2 之后每加一个功能都是重复劳动。

## 建议的决策方法（半天）

1. 用 URP 建一个临时场景
2. 把 Lake 的地形、水体、天空摆进去
3. 用**同样的美术资源**渲染一张图
4. 和现在的自建管线渲染图并排对比

**如果 URP 版本明显更好看** → 问题在基建，考虑迁移
**如果两者差不多** → 问题在内容（材质/植被），先补 P0/P1

> 这个实验能把"感觉丑"变成"可比较的证据"，值得花半天。

---

# 五、不做的事

| 项 | 原因 |
|---|---|
| 继续在自建管线上堆视觉功能 | 每加一个都要自己接，且 6.5 会失效 |
| 只调参数不改结构 | 已经证明调参数救不了"缺内容层" |
| 一次性大重构 | 风险高；按 P0→P1→P2 分批，每批可验证 |
