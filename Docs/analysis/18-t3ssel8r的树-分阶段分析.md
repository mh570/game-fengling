# 阶段 1：他说了什么（一手资料）

**[Procedural Pixel Art Trees · 2020-11-08](https://www.gamesinprogress.com/indie-game-developers/t3ssel8r/procedural-pixel-art-trees)**

> "Some **jagged spheres** are used as **shadow-casters** and a bunch of **randomly-placed leaf sprites** are drawn over them, **lit using the sphere normal**. The initial results look ok, but **still a bit too messy** compared to artist results. I think I need to work on a **more evenly-distributed sprite placement, perhaps using blue noise**, like I did with the grass."

拆成 5 条技术要求：

| # | 原文 | 含义 |
|---|---|---|
| 1 | **jagged spheres** | 树冠是**锯齿状**的球（不是光滑球） |
| 2 | **shadow-casters** | 球**要投射阴影**，所以球本身是实体、可见的 |
| 3 | **randomly-placed leaf sprites** | 叶片是**精灵**（带 alpha 的方片），贴在球上 |
| 4 | **lit using the sphere normal** | 光照用**球体法线**（从球心发散 → 天然渐变） |
| 5 | **evenly-distributed / blue noise** | 叶片要**均匀分布**，纯随机会"too messy" |

# 阶段 3：结构反推

综合原文和像素：

```
① 锯齿球（14×10 细分，±18% 顶点抖动）
   ├─ 作用：体积、轮廓、投影、球面法线
   └─ 颜色：绿色（和叶片同色系，不能更暗）
        ↓
② 叶片精灵贴在球面外 1.1~1.3 倍
   ├─ 数量：几千（均匀分布，非纯随机）
   ├─ 尺寸：小（游戏分辨率下 1~3 像素）
   └─ 贴图：纯白 + alpha（不能有内部明暗）
        ↓
③ 光照：球体法线 + 平滑（非硬分档）+ 环境光
```

**关键参数反推**（从"看不见单片叶子"推断）：

| 参数 | 推断值 | 依据 |
|---|---|---|
| 叶片最终屏幕尺寸 | **1~3 px** | 参考图放大后看不到单片形状 |
| 叶片数量 | 5000~10000 | 覆盖整个球面且均匀 |
| 着色档数 | **平滑或 ≥16 档** | 参考图无可见色带 |
| 明度 | 树冠 0.55~0.65 | 采样值 |
| 饱和度 | 低（R:G:B 1:1.19:0.84） | 采样值 |

| 草地 | `(0.482, 0.612, 0.588)` | `(0.600, 0.710, 0.345)` | **蓝分量 −0.24** |

## 4.2 已修复的问题（按发现顺序）

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 树像葡萄 | 几个大球 | 壳 + 叶片卡片 |
| 2 | 叶片像彩纸 | 纯随机分布 | **Fibonacci 均匀分布** |
| 3 | 树干变细条 | 平面着色 + 细分太少 | 平滑法线 + 8 边 |
| 4 | 树干浮空/太短 | 树冠压太低 | canopyBase ×1.30~1.45 |
| 5 | 树不投影 | shader 缺 `CBUFFER_START` | 加 CBUFFER |
| 6 | 地面怪影 | `cloudContrast = 20` | 降到 4 / 关闭 |
| 7 | 满树白点 | **叶片贴图内部有明暗** | 纯白 + alpha |
| 8 | 暗点噪斑 | **壳色太暗，从缝隙透出** | 壳与叶片同色 |
| 9 | 毛边 | 卡片飞到球外 | 卡片收到 1.10~1.30 倍 |
| 10 | 空隙 | 壳缩到 0.88 | 壳恢复全尺寸 |
| 11 | 没有渐变 | 壳被藏起来 | 壳露出来，法线从球心发散 |
| 12 | 整体发暗 | **shader 没有环境光** | 加 `SampleSH(N)` |
| 13 | 色相偏黄 | 调色板用黄绿 | 改成青绿（采样值） |

## 4.3 仍未修复

| # | 问题 | 现象 | 方向 |
|---|---|---|---|
| **A** | **整体仍偏亮 ~0.15** | 树冠 0.71 vs 0.55 | 继续压 `_HighlightColor` 和顶点色 |
| **B** | **表面有细碎斑点** | 叶片个体在最终分辨率仍可见 | 卡片再缩小 / 提高渲染缩放比 |

# 阶段 5：结论与下一步

## 5.1 结构已完全一致

**阶段 3 推断的四层结构，我们全部实现了。** 差的只有调色和分辨率。

## 5.2 剩余三个问题的共同根源

**A（偏亮）和 C（渐变弱）其实是同一个问题**：
环境光 `SampleSH(N) * 0.45` 加得太均匀，把所有面都提亮了 → 平均亮度上升，同时对比度下降。

**修法**：
```hlsl
// 环境光也要乘球面法线的方向权重，而不是均匀加
float3 ambient = SampleSH(N) * 0.30;   // 降低
// 并让主光占更大比例
col = albedo * (mainLight + ambient)     // 主光对比更明确
```

**B（斑点）**是分辨率问题：
叶片在 512×512 渲染下约 3~5px，可见。需要：
- 卡片再缩小（0.10 → 0.06）
- 或数量再增加

## 5.3 优先级

| 序 | 动作 | 预期收益 |
|---|---|---|
| 1 | 降环境光到 0.30，提主光强度 | 同时修亮度和渐变 |
| 2 | 卡片 0.10 → 0.06，数量 9000 → 14000 | 消除斑点 |
| 3 | 整体亮度再压 10% | 对齐采样值 |
