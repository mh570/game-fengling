# 06 · 超大地图不卡的做法

**日期**：2026-11-21
**需求**：一座大岛（约 2km），俯视视角，要"超大且不卡"
**问题**：把 2km 的地形 + 几千棵树一次全画出来，必然卡

---

# 一、行业通用做法

## 1. 分块 + 流式加载（Chunk + Streaming）

**核心**：世界切成固定大小的块（tile），只保留玩家附近若干块，远处卸载。

| 实现 | 特点 |
|---|---|
| [BigWorldStreamer](https://assetstore.unity.com/packages/tools/terrain/bigworldstreamer-324077) | 四叉树分块、AssetBundle 管理、植被/碰撞体一起流式 |
| [TYLER](https://assetstore.unity.com/packages/tools/terrain/tyler-183873) | 原生 Terrain 分块 + 三级 LOD 同时存在 |
| [Terrain Pooling](https://assetstore.unity.com/packages/tools/terrain/terrain-pooling-huge-terrain-optimizer-310124) | 大 Terrain 动态切成小块，只渲染视野内 |
| [WorldStreamer2](https://blog.csdn.net/qq_41140324/article/details/155714352) | 分块 + 流式 + 远景低模替换 + 异步加载 |

**要点**：流式加载必须**异步**，否则会出现加载卡顿。

## 2. 视距分级 LOD

按距离分近/中/远三层，**交界处加渐变带**避免硬切断层。

参考实践：25–35 米和 90–110 米交界各加 10 米过渡带，移动端帧率提升 40%。来源：[3D 开放世界地形开发](https://developer.unity.cn/projects/68f4e3e2edbc2a00244ee4da)

## 3. 道具 LOD + Impostor

树/石头/建筑按距离换模型：LOD0（近）→ LOD1 → LOD2（远）→ **Impostor（八面体/billboard 贴图）**。

[BigWorldGPULod](https://assetstore.unity.com/packages/tools/utilities/bigworldgpulod-338992) 的做法是每个资产最多 3 级 LOD + GPU 驱动。

**对于俯视 RTS 视角，Impostor 是必须的**——相机拉远时能看到上千棵树。

## 4. 纹理 LOD

贴图按距离切分辨率（4096 → 1024），配合 Mipmap 链动态生成。来源：[端游开放世界资源调度](https://developer.unity.cn/projects/68f755cbedbc2a001ee1c81c)

# 二、我们的具体方案

## 尺度规划

| 项 | 值 |
|---|---|
| 岛尺寸 | 2048 × 2048 |
| 分块 | **16 × 16 块，每块 128 单位** |
| 每块内容 | 地形网格 + 植被实例 + 碰撞体 |
| 常驻块 | 相机周围 5×5（640 单位范围） |
| 远景 | Impostor 树 + 简化地形网格 |

## 三级 LOD

| 距离 | 地形 | 树 |
|---|---|---|
| 0–150 | 完整网格 | LOD0（近景模型） |
| 150–400 | 半分辨率网格 | LOD1（中景模型） |
| 400–1200 | 简化网格 | **Impostor** |
| > 1200 | 不渲染（雾遮住） | 不渲染 |

## 异步

- 分块加载放到 `Unity Job` 或协程，每帧最多加载 1 块
- 植被实例化用 `Graphics.DrawMeshInstanced`，按块提交

## 性能预算（720p，独显，目标 60fps = 16.6ms）

| 项 | 预算 |
|---|---|
| 地形 | 3 ms |
| 植被 | 4 ms |
| 水体 | 2 ms |
| 天空/云 | 2 ms |
| 阴影 | 2 ms |
| 后处理 | 1.5 ms |
| 其他 | 2 ms |

---

# 三、差距

| 项 | 我们 | 行业做法 | 性质 |
|---|---|---|---|
| 分块 | 完全没有（单个 2048 地形） | 16×16 块 | **缺功能** |
| 流式 | 没有 | 异步加载/卸载 | **缺功能** |
| LOD | 没有 | 三级 + 渐变带 | **缺功能** |
| Impostor | 没有 | 远景贴图树 | **缺功能** |
| 植被实例化 | 没有 | GPU instancing | **缺功能** |

**结论：超大地图的"不卡"全部来自这四件事，我们一件都没有。**

---

# 四、分阶段计划

## 阶段 1：先让画面像样（不做流式）

- 单一地形，但做**地表色块化**
- 树用 **GPU instancing** 一次性摆，但只摆相机周边 300 单位内的
- 远景用**雾**遮住，避免看到"空岛边缘"

**收益**：画面立刻改善，不做复杂系统。

## 阶段 2：分块 + 流式（地形）

- 把 2048 地形切成 16×16 块
- 相机移动时加载/卸载
- 验证：连续移动 1000 单位，帧时间波动 < 3ms

## 阶段 3：植被 LOD + Impostor

- 树按距离换模型
- 远景用 billboard
- 验证：视野内 2000 棵树，帧时间 < 6ms
