# 05 · 风格化美术规范

**日期**：2026-11-21
**方向**：风格化俯视森林（参考 `09-参考风格-风格化森林与面片体积光.md`）
**目标形态**：**一座大岛**，俯视 RPG 视角

---

# 一、总原则

1. **视觉一致性 > 真实感**（参考 Dungeons of Hinterberg 的结论）
2. **有限调色板**：所有资产必须落进下面 4 组色系
3. **简化着色**：漫反射为主，弱高光，低对比
4. **silhouette 优先**：远看能认出是树/石/草，比细节重要

---

# 二、调色板（有限、低饱和）

| 组 | 用途 | 色值参考（sRGB） |
|---|---|---|
| **草绿** | 草地、灌木 | `#7FA05A` / `#96B36B` / `#5E7C46` |
| **深绿** | 树冠暗面、密林 | `#3F5B3A` / `#4E6B42` |
| **土色** | 土路、沙岸 | `#C9B393` / `#B39B7A` / `#8C7559` |
| **灰紫** | 岩石、阴影地面 | `#6E6A7A` / `#5A5666` |
| **点缀** | 花、发光物 | `#F2E8A0`（黄白）/ `#B58FD1`（紫） |

**禁止**：高饱和纯色、纯黑纯白、写实照片纹理。

---

# 三、着色简化规则

| 项 | 现在（写实） | 改成（风格化） |
|---|---|---|
| 光照 | PBR（金属度/粗糙度） | **漫反射为主** + 固定 0.2 高光 |
| 对比 | 强（明暗分明） | **弱**（提高环境光，压低直射对比） |
| 阴影 | 硬边级联阴影 | **柔和**，强度降一半 |
| 水面 | 平面反射 + 折射 | **纯色 + 波纹法线 + 菲涅尔**，弱反射 |
| 云 | 体积光步进 | **图层云**（简单、便宜） |
| 后处理 | Bloom/ACES | **轻微**，避免过曝发白 |

---

# 四、地图形态：一座岛

## 尺度

| 项 | 值 | 说明 |
|---|---|---|
| 岛尺寸 | **2048 × 2048 世界单位**（约 2km） | "超大"但对单人可控 |
| 高度范围 | 0（海平面）~ 180 | 沙滩→丘陵→山脊 |
| 分带 | 海岸 → 沙滩 → 草地 → 森林 → 岩山 | 按高度 + 噪声打破边界 |
| 地形网格 | 高度图（现有 `CoastHeightMap`） | 分辨率建议 512×512 采样 |

## 分带规则（地表色块）

```
h < 0.08          → 沙滩（土色）
0.08 ≤ h < 0.45   → 草地（草绿，多档）
0.45 ≤ h < 0.75   → 密林地表（深绿）
h ≥ 0.75          → 岩石（灰紫）
坡度 > 45°        → 强制岩石（不管高度）
```

**边界处理**：用低频噪声扰动分带阈值，避免出现等高线一样的硬边（参考图的土路就是这种柔和过渡）。

# 六、树与草的规格

## 树（三种规格，覆盖远近）

| 类型 | 面数 | 用途 | 说明 |
|---|---|---|---|
| 远景树 | < 200 | 山脊线、密林背景 | 单个团块即可 |
| 中景树 | 200~600 | 主要植被 | 树干 + 2~4 个团簇树冠 |
| 近景树 | 600~1500 | 相机附近 | 树冠有层次、有斑块感 |

**树冠做法**（参考图就是这种）：几个**扁球/面包块**拼接，表面用色块噪声，不用真实叶片。

## 草

- **不用模型**：用地表 shader 的色块 + 少量 billboard 草丛
- 近处：instanced 草片（十字面片）
- 远处：纯色块

## 花

- 十字/星形小面片，散落密度约 **每 100 单位 3~5 个**
- 颜色只用调色板里的黄白和紫

# 七、验收标准

| 项 | 标准 |
|---|---|
| 调色板 | 截图取色，所有像素落在 5 组色系内 |
| 地表 | 从沙滩到山脊能看出分层，边界柔和无硬边 |
| 树 | 远看是团块，近看有层次 |
| 光柱 | 有面片叠加的竖直光柱，柔和 |
| 整体 | 和参考图并排看，**风格一致** |
