# 3D 像素树的制作流程（资料汇总）

**日期**：2026-11-22
**来源**：多个教程交叉验证

---

# 一、核心结论：树是"壳 + 卡片"

> "The tree mesh is built using **three simple inflated shapes to create a layered shell**.
> Place some **leaf cards** here and there to build... Then shifted randomly each leaf card in X"
> —— [Ghislain GIRARDOT, ArtStation](https://www.artstation.com/artwork/Vyz12R)

另一位教程（[风格化 3D 像素树的搭建｜Godot + Blender](https://www.snm0516.aisee.tv/zh-Hans/video/BV1YcHG62Eri/)）描述的流程：

> "**长枝干、搭叶团、撒叶片卡片、上光、像素化**，最后用同一套做法做了九种植物"

**两边说的是同一件事：**

```
1. 长枝干    → 圆柱 + 锥度 + 分歧
2. 搭叶团    → 3 个大圆的"充气壳"叠成树冠体积
3. 撒叶片    → 在壳表面随机撒平面卡片（带叶片贴图）
4. 上光      → 法线朝上/朝外（球形法线）
5. 像素化    → 低分辨率渲染
```

# 二、详细步骤（Blender）

## 2.1 树干

```
1. 加圆柱体（Cylinder），顶点数 8~12
2. 编辑模式：顶部缩放到 0.4（锥度）
3. 加 2~3 根分枝：从树干中上部挤出，旋转 40~60°
4. 根部：底部稍微外扩（像个喇叭口）
5. 材质：深棕 #3A2A20，纯色不要贴图
```

## 2.2 树冠"壳"（关键）

```
1. 加 3 个 UV 球，半径分别 3.0 / 2.2 / 1.6
2. 上下位置错开，形成不规则的团
3. 全部加 Displace 修改器
   - Texture: Clouds（噪波）
   - Strength: 0.5~0.8
   - 这让球面变得凹凸不平
4. 加 Remesh 修改器（或者 Decimate）
   - 模式：Blocks 或 Voxel
   - 让表面变成块状（低多边形感）
```

**为什么用"壳"**：给叶片卡片一个**可依附的表面**，而且壳本身提供体积和遮挡。

## 2.3 叶片卡片（关键）

```
1. 做一个叶片簇 PNG（32×32 或 64×64，透明背景）
   - 5~8 个小椭圆随机分布
   - 硬边、像素风
2. Blender 里加 Plane，贴上叶片贴图
3. 用粒子系统或 Geometry Nodes 撒到"壳"表面：
   - Count: 300~800
   - Size: 0.3~0.6（相对树冠要小）
   - Rotation: 完全随机（XYZ 都随机）
   - Offset: 沿法线外偏移 0.05
4. 每个卡片的位置随机抖动（±0.2m）
```

**这一步是"葡萄感"的解药**：不是球，是几百张随机朝向的小卡片。

## 2.4 法线处理

两种做法：

| 做法 | 说明 |
|---|---|
| **在 Blender 里改法线** | 全选叶片 → `Mesh > Normals > Point to Center`（或手动） |
| **在 shader 里改**（推荐） | 顶点着色器里 `normal = normalize(vertex - canopyCenter)` |

**shader 里改更好**：不用改模型，可以调混合系数。

## 2.5 导出

```
File > Export > glTF 2.0 (.glb)
  ✔ Selected Objects
  ✔ +Y Up
  ✔ Apply Modifiers
```

# 三、Unity 侧的对应设置

| 项 | 设置 |
|---|---|
| 材质 | `Custom/ToonLit`（t3ssel8r 管线那套） |
| 法线 | shader 里球形重映射，blend **0.5~0.6**（太满会失去叶簇细节） |
| 描边 | 靠 5 步管线的 Outline pass（**不要**给树叶单独加描边 pass） |
| 草 | 用 `GrassBlade`，**颜色继承地形 patch** |

# 四、为什么我们之前做的树像葡萄

| 我们的做法 | 应该的做法 |
|---|---|
| 几个大球堆起来 | **壳 + 几百张小卡片** |
| 球面就是最终表面 | 球面只是**依附表面**，视觉上是卡片 |
| 法线 = 球面法线 | 法线 = **球形重映射**（从树心往外） |
| 单色 | 卡片有**叶片贴图**（alpha 裁剪） |

**核心差距：我们的"叶子"是几何体本身；真正的树"叶子"是贴在几何体上的卡片。**

# 五、如果不想建模（备选）

| 方案 | 说明 |
|---|---|
| **用 SpeedTree** | Unity 内置工具，可调叶片密度，导出后能用（付费/订阅） |
| **买资产包** | 搜 "stylized tree pack pixel"，最省事 |
| **Blender 的 Sapling 插件** | 免费，能生成枝干 + 叶片卡片，但叶片形状要自己调 |
