# 二、已经完成

## 1. 相机 / 场景

- RTS 透视相机

- 地形/水面约束

## 2. 真实日月天文

- 24 小时时钟
- 真实日期 `2026-11-20`
- 太阳黄经 / 高度 / 方位
- Meeus 月亮黄经 / 黄纬
- 月相角 / 照亮比例
- 月光强度 = 高度 × 月相
- 月盘相位、月海、环形山、地照

## 3. 太阳阴影

- 4 级级联
- 4096 统一 shadow atlas
- 2048 / 1024 / 1024 / 512
- 5×5 PCF
- normal bias
- 级联混合 / 距离淡出
- 按需更新

## 4. 月亮真实阴影

- 独立 2048 moon shadow map
- 全场景可见 caster
- 按月亮 light index 计算 view/proj
- 月相 × 云量 × 低角度强度淡出
- 真机成本约 +0.3ms

## 5. 天气

- `WeatherSystem`
- cloudCover / haze / fog / rain / snow / wind
- 云量遮挡日月、降低阴影
- 雾/霾影响天空、水面、体积光
- 雨雪影响光照

## 6. 云

- 远 / 中 / 近三层 skybox 云
- 云层受太阳色影响
- 风向漂移
- 地面云影
- 水面云影

## 7. 雨 / 雪

- 放弃 ParticleSystem
- Mesh 雨：相机前方体积、4000 条、风偏、深度淡出
- Mesh 雪：慢速下落、漂移
- 雨雪已可见

## 8. 水面

- 平面反射
- 深度 / 颜色
- 太阳高光
- 天气降低反射 / 高光
- 云影
- 雾衰减
- 程序化雨纹（代码已接，未单独验收）

## 9. GodRay（部分完成）

- 屏幕空间 radial GodRay
- 32 步 × 3 tap
- 柱间光柱可见
- 仅雾/霾启用
- 高云量 / 强雨关闭
