# 体积云实现方案

**日期**：2026-11-21
**决策**：直接做体积云（不走"先加视差"的过渡方案）
**前提**：光柱（阳光穿云缝）是氛围重点，天空盒云提供不了透射率，必须体积化

---

# 一、现状

当前是 **2D 天空盒层**（`FenglingSkybox.shader` 三层平面投影 + fbm）：

| 特性 | 现状 |
|---|---|
| 视角透视（地平线拉伸） | ✅ |
| 体积 / 厚度 / 侧面 | ❌ |
| 视差（相机移动错动） | ❌ |
| 云缝透光 / 光柱 | ❌（云只改天空颜色，不参与光传输） |

低仰角处会看到 fbm 拉伸成的白色小块伪影。

---

# 二、目标

1. 云有**体积感**：从下方能看出云的厚度与明暗
2. 太阳被云遮挡有**自阴影**（银边、云底发暗）
3. 能算出**透射率**，供光柱使用
4. 性能可控：半分辨率 + 可开关 + 按天气调节

---

# 三、实现步骤

## 3.1 密度场

- 云层高度区间：`H0 = 600`，`H1 = 1200`（世界单位，按场景尺度再调）
- 基础密度：3D fbm（可用 2D fbm + 高度衰减近似，省一次采样）
- 覆盖度：`_CloudCoverage` 控制阈值
- 天气：`cloudCover / haze` 驱动覆盖度

## 3.2 光线步进

```
1. 相机射线与云层 AABB 求交
2. 在 [tMin, tMax] 内按固定步数（如 48）步进
3. 每步采样密度，累积：
   T *= exp(-density * stepSize * extinction)
   S += T * density * sunColor * phase
4. 输出 (S, T)
```

## 3.3 自阴影

每步向太阳方向做 4~6 次短步进，累积遮挡 → 得到该点被上方云遮住多少。这是"云有体积"的关键。

## 3.4 合成

- 半分辨率 RT（宽高各 1/2）
- 深度感知：比场景深度更远的云才画
- 上采样到全分辨率，与主画面混合

## 3.5 光柱

体积云算出的 `T`（透射率）写入一张半分辨率纹理，光柱 pass 采样它：
**云缝处 T 高 → 光通过 → 出现光柱**。

---

# 四、性能策略

参考 HDRP 与社区经验（全体积云不降采样会很贵）：

| 手段 | 说明 |
|---|---|
| 半分辨率 | 先决条件，不是优化项 |
| 步数分级 | 晴天 24 步，阴天 48 步 |
| 可开关 | 相机拉远 / 低端机可关 |
| 只在地面视角启用 | 相机高于云层时跳过 |

**目标**：体积云 + 光柱合计 ≤ 3ms（720p，独立显卡）。

---

# 五、风险

| 风险 | 应对 |
|---|---|
| 全屏 raymarch 在自建 SRP 里接入复杂 | 先用 unsafe pass 塞进去，跑通再转 raster pass |
| 半分辨率上采样出现锯齿/闪烁 | 先不做时域 AA，接受轻微抖动；必要时加蓝噪声 |
| 与现有天空盒云叠加导致双层云 | 体积云启用时，天空盒云的中/近层关闭 |
| 与光柱 pass 的顺序 | 体积云必须在光柱之前，且透射率纹理要被光柱采样 |

---

# 六、验收

| 项 | 标准 |
|---|---|
| 云有体积 | 从地面仰视能看到云的厚薄与明暗变化 |
| 自阴影 | 云底比云顶暗 |
| 光柱 | 云缝处能看到光柱，密云处没有 |
| 性能 | 720p 下增量 ≤ 3ms |
| 不破坏现有 | 探针三块采样偏差 < 5 |
