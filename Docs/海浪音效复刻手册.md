## 1. 真实海浪声的四个来源

一条浪拍上沙滩，不是一个声音，是四个物理过程同时发生：

| 来源 | 频段 | 听感 | 物理机制 |
|---|---|---|---|
| **水体涌动** | 20–200 Hz | "轰——" | 大质量水的整体运动 |
| **气泡破碎** | 200 Hz – 2 kHz | "哗"（主体） | 气泡在水中共振 |
| **沙砾摩擦** | 2–8 kHz | "沙沙"（尾巴） | 水退时沙粒互相摩擦 |
| **拍击瞬态** | 全频段 | "啪"（起音） | 水体撞击滩面的瞬间 |

### 气泡为什么会响

单个气泡的共振频率由半径决定（Minnaert 公式）：

```
f₀ ≈ 3.28 / r        （r 单位：米）
```

| 气泡半径 | 共振频率 |
|---|---|
| 10 mm | 328 Hz |
| 5 mm | 656 Hz |
| 1 mm | 3,280 Hz |

海浪里气泡大小是连续分布的，所以声音是一个**宽带**，而不是某个音高。这也解释了为什么合成海浪很难——你得同时生成几百个不同频率的共振峰。

### 两条时间特征

- **起音极快**：1–3 ms 到达峰值（人的听觉在 5 ms 内就能定位瞬态）
- **衰减很长**：3–8 秒，随水退回慢慢消失

**结论：不可能用一条完整录音循环播放。** 循环会听出节奏，而每条浪的形态都不一样。

## 2. 四层结构

| 层 | 作用 | 播放方式 | 音量 |
|---|---|---|---|
| **Bed** 底噪 | "我在海边"的空间感 | 循环 | -18 ~ -12 dB |
| **Impact** 拍岸 | 主体事件 | 随机 one-shot | -6 ~ -3 dB |
| **Foam** 泡沫 | 颗粒感、细节 | 跟随 Impact | -20 dB |
| **Transient** 瞬态 | 水花、碎石、水滴 | 点状 one-shot | -12 dB |

四层的关系：

```
Bed ──────────── 常驻，提供基底
Impact ─── 事件，随机触发
   ├─ Foam ── 与 Impact 同步，补高频
   └─ Transient ── 与 Impact 同步，补瞬态
```

**只做 Bed 会像白噪声，只做 Impact 会像在放音效素材。** 必须叠。

## 3. 每层的做法与参数

### 3.1 Bed（循环底噪）

| 参数 | 值 |
|---|---|
| 样本长度 | 20–40 秒 |
| 循环 | ✅ |
| spatialBlend | **0（2D）** |
| 音量 | -15 dB |

**为什么用 2D**：环境底噪不该随相机位置忽大忽小，否则转头就变调。

**循环点必须切在零交叉处**，否则每 30 秒"啪"一声。做法：

1. 在波形上找振幅接近 0 的点
2. 前后各留 10–20 ms 做交叉淡化
3. 播放一遍听接缝

### 3.2 Impact（拍岸）

| 参数 | 值 |
|---|---|
| 样本数量 | 3–5 条不同形态 |
| 间隔 | **4–12 秒随机** |
| 音量 | -6 dB ± 3 dB 随机 |
| pitch | 0.92 – 1.08 随机 |
| spatialBlend | 1（3D） |

**间隔不能等距。** 等距就是节拍器，会破坏"自然"。

随机参数的范围要"看起来乱、听起来稳"：pitch 超过 ±10% 会明显变调，低于 ±3% 又听不出变化。

### 3.3 Foam（泡沫层）

| 参数 | 值 |
|---|---|
| 内容 | 高频"沙沙"，2–8 kHz 为主 |
| 触发 | 与 Impact 同时 |
| 时长 | 略长于 Impact（尾巴） |
| 音量 | -20 dB |

作用：给拍岸加"颗粒"。没有它，拍岸只剩低频，像闷鼓。

### 3.4 Transient（瞬态）

- 水花溅起、小石子、水滴
- 音量很低（-12 dB），出现率约 30%
- 作用：打破规律感，增加"现场感"

## 4. 和画面同步

这是"高级感"和"廉价感"的分界线。

### 4.1 用浪高驱动（最有效）

拿到当前浪高，映射成音量和滤波：

```
浪高 0.3 m  →  音量 -12 dB，低通截止 4 kHz（轻浪）
浪高 1.5 m  →  音量 -3 dB，低通截止 12 kHz（大浪）
```

数据来源三选一：

| 来源 | 说明 |
|---|---|
| 着色器/GPU 回读 | 最准，但要处理异步回读的延迟 |
| CPU 端波形计算 | 简单，CPU 算一遍同样的 Gerstner 就行 |
| 手动关键帧/曲线 | 最省事，适合固定演出 |

HDRP 自带一个 `WaterAmplitudeEvaluator`，用 Burst 在 GPU 上算最大位移（32 次迭代 × 512 时间步），可以直接拿来当参数源。

### 4.2 传播延迟

如果海面有明确的浪源方向，拍岸声要比涌浪**晚一点**到：

```
延迟 = 浪到岸的距离 / 波速
深水波速 v ≈ √(g·λ / 2π)
```

例：波长 20 m，v ≈ 5.6 m/s；离岸 50 m 的浪，延迟约 9 秒。

这个延迟人耳能感觉到"空间深度"——远处涌起、近处拍碎，声音是有先后的。

### 4.3 水下

| 处理 | 参数 | 效果 |
|---|---|---|
| 低通滤波 | 截止 **600–900 Hz** | 闷、远 |
| 混响 | 0.6–1.2 s，湿 30% | 水下空间感 |
| 音量 | -6 dB | 水下听得更"近"但更糊 |

用 AudioMixer 的 Snapshot 切换，进/出水时 0.3–0.5 秒过渡。

## 5. 空间化

### 5.1 衰减曲线

| 层 | 曲线 | 范围 |
|---|---|---|
| Bed | 不衰减（2D） | — |
| Impact | 对数 | 5–40 m |
| Foam | 对数 | 3–20 m |

**为什么 Impact 用对数**：对数衰减符合人耳对响度的感知（每 10 倍距离约 -20 dB）。线性衰减听起来"远处突然消失"。

### 5.2 距离与频段

空气会吸收高频。距离越远，高频越少：

| 距离 | 保留频段 |
|---|---|
| 0–20 m | 全频 |
| 20–100 m | 高频衰减 6 dB |
| 100 m+ | 高频衰减 12 dB+ |

做法：给距离挂一个低通，截止频率随距离降低（10 kHz → 2 kHz）。

### 5.3 多普勒

对**固定的海岸线不需要**。只有在有船、有移动声源时才开，而且强度要调低（0.3 左右），否则像赛车游戏。

## 6. 混音

### 6.1 总线结构

```
Master
├─ Ambient（环境）
│  ├─ Waves_Bed
│  ├─ Waves_Impact
│  ├─ Waves_Foam
│  └─ Waves_Transient
├─ SFX（鱼线、水花、脚步）
└─ Music
```

### 6.2 侧链

- 拍岸（Impact）响起时，把 Ambient 轻微压一下（-2 dB，50 ms 释放）
- 作用：让瞬态更突出，不会糊成一团

### 6.3 目标响度

| 类型 | 目标 |
|---|---|
| 休闲游戏整体 | -16 ~ -20 LUFS |
| 环境层（单独） | 比主要 SFX 低 8–12 dB |
| 真峰值 | ≤ -1 dBTP |

环境音**必须让位**给玩法反馈（鱼咬钩的"叮"）。宁可环境小一点。

## 7. 素材从哪来

### 7.1 自己录（最划算）

- 手机 + 防风罩，离水面 5–10 m
- 录 3–5 分钟，能切出：1 条循环底噪 + 3–5 条拍岸样本
- 避开：风噪（用防风罩）、鸟叫（挑清晨/傍晚）、人声

### 7.2 素材库

| 来源 | 许可 | 说明 |
|---|---|---|
| Freesound.org | CC0 / CC-BY | 搜 "ocean waves beach"，量大但质量参差 |
| Unity Asset Store | 免费包 | 方便，但被用烂了 |
| 商业库（Boom Library 等） | 付费 | 质量最好 |

### 7.3 合成

海浪合成很难做对，因为需要同时模拟几百个气泡共振。**除非要做风格化（比如"水声很脆的游戏"），否则不建议合成。**

## 8. 组装顺序与验收

### 8.1 步骤

| 步骤 | 做什么 | 验收 |
|---|---|---|
| 1 | 一条 Bed 循环 | 听不出接缝 |
| 2 | 3 条 Impact + 随机触发 | 听不出节奏 |
| 3 | Foam 跟随 | 拍岸有"颗粒" |
| 4 | 距离衰减 | 走远变轻、不突变 |
| 5 | 浪高驱动音量 | 大浪时明显更响 |
| 6 | 水下 Snapshot | 入水瞬间变闷 |
| 7 | 侧链 + 总线 | 不糊、不刺耳 |

### 8.2 三条验收

1. **闭眼听**：能想象出海边（不是"白噪声"）
2. **听 1 分钟**：听不出循环点和节拍
3. **和画面一起看**：浪打上去时，声音正好到

## 附录 C 常见错误

按踩中概率排序：

1. **只用一条样本循环** —— 30 秒后玩家就听出来了
2. **Impact 等间隔** —— 像节拍器
3. **循环点没对齐零交叉** —— 周期性"啪"一声
4. **没有低频层** —— 听起来像"沙沙的白噪声"
5. **拍岸和画面不同步** —— 看到浪打了却没声
6. **环境音盖过玩法反馈** —— 鱼咬钩听不见
7. **Bed 用 3D** —— 转头时音量忽大忽小
8. **距离用线性衰减** —— 远处突然消失
9. **pitch 随机超过 ±10%** —— 明显变调，像坏掉的播放器
10. **没有任何随机化** —— 听两遍就腻
