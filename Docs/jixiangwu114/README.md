## 命名约定

文件名前缀带日期，排序即时间顺序：

```
2026-11-19_标题.md
```

- 同一天有多份，末尾加序号：`2026-11-19_标题_02.md`
- 标题用中文，不加空格，词之间用下划线分隔
- 只有 `README.md` 不带日期前缀，它是本目录的索引

## 文档内格式

每份文档开头统一写时间头，方便追溯是哪天的结论：

```markdown

> 创建：2026-11-19 22:29 (+08:00)
> 更新：2026-11-20 09:10 (+08:00)

## 结论

## 背景

```
